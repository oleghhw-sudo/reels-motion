# Передача архитектору (Claude Opus 5.5): что изменено 2026-10-18 и как продолжать

Кому: архитектор проекта (облачный чат, Opus 5.5). От кого: облачная сессия Claude Code (ветка `claude/exciting-hamilton-t42s0r`, модель Fable 5.1). Заказчик правок: Олег.
Запрос Олега, дословно по смыслу: «прошерстить скиллы, найти ошибки, чтобы motion был живым, пластичным, активным, не банальным; посмотреть опыт Opus 5.5 в визуале/рендере/motion; добавить эффекты уровня After Effects и постобработки; посмотреть стили, которые заходят; записать задумку «искажение реальности» как вариант; затем — перепроверить с полным доступом к сети и сделать этот файл».

Ничего из `src/`, `videos/`, `approved/`, `sfx/`, `env.manifest.json`, `package.json` **не менялось**. Все правки — документы, скиллы и задачи. Код по гейту 7 и протоколу ролей — за билдером после «да» Олега.

## 2. Приоритеты между скиллами (как теперь читать)
1. Гейты CLAUDE.md (как и раньше) → 2. номера motion-prompt, выбранные Олегом (ровно по спецификации) → 3. readcheck для текста → 4. **режим брифа** решает, действует ли living-motion §12 целиком (editorial) или cinematic-fx §1 (доза) → 5. физика движения (living-motion §1–§11) одинакова во всех режимах → 6. beat-sync ставит удары и склейки на сетку, карта ударов брифа задаёт размер S/M/L → 7. motion-review проверяет движение (лист удара, энергия), не только стиллы.
Исключения стиля записываются в бриф (пример: Swiss-стиль разрешает eyebrow-метки «01 / 06», запрещённые §12).

### А. Числа AE/Premiere/CapCut (cinematic-fx §2–§7, ANALYSIS §3.2)
Подтверждено по первоисточникам: beat-zoom 108–112 % (+ дозировка по весу доли 12–15 / 5–8 %); ramp 30–50 % за 8–15 кадров, hold 1–3 с, < 10 % ступенит; zoom-through 20 кадров / blur 60 / 250 %; Directional Blur 90°/250; VHS-рецепт (Wave Warp Square 600/180°/0.1, Noise 45); light leak — Screen и выравнивание пика на склейку; luma-fade — клише; inertial bounce .1/2/2; свист пикует на кадре смены, «50 мс раньше — неряшливо», длина ≈ перехода, громкость ≈ половина голоса; дакинг 6–12 дБ / 30–80 мс / 250–700 мс, порог −28…−20 dBFS; Netflix 17/13 cps, событие 5/6–7 с; hormozi по ascynd (Montserrat Black, 100 px, обводка 10 px, #FFD93D, Y ≈ 65 %, pop ≤ 105 %); антипаттерны («один свист на 40 склейках», > 2–3 типов переходов, статичные планы).
**Исправлено:** спин — 360° за 20 кадров (10+10) с затвором 180° (было 10 кадров / 360°); хлёст в Premiere — 5 кадров до + 10 после (было 5+5, источник исчез); wiggle — `wiggle(1,25)` тонко / `(1,35)` ручная / `(3,55)` бег / `(5,10)` резкая (ранее указанные «wiggle(5,1)», «5 px/50 px», «2–3 / 5–8 px» не подтвердились); слой при тряске 107 % (было 106–120 %); зерно Resolve — настроить при 1.0, затем ≈ 30 % (было «15–30 в Grain»); hormozi pop ≤ 105 % в точном варианте, 110–120 % — общий кинетический диапазон; размер hormozi 100 px, не «80 px+».
**Переведено в гипотезы (источник не подтверждает):** AE Glow «63 % / 17 / 3.6»; Deep Glow дефолты; light leak «70 %»; riser 2–4 доли (источник: ≈ 1 с); полосы удара 3 кГц / 200–500 / 40–80 Гц; «2–3 эмодзи»; разгон 250–500 %; halation-рецепт.
**Добавлено:** Sapphire S_Shake дефолты (Amp 1, Freq 8 Гц, Rand 0.2, Wave 0.5 Гц, Mo Blur 1.0), Red Giant Camera Shake (Amount 100 / Freq 1.0; сильный пример 175/4), Premiere-гайд по zoom-punch (105 %, ±2 кадра, 1–2 на раздел), Offset 960→−960 и Posterize 15 на хлёсте, правило fps для ramp (60 → ×2.5, 120 → ×5). Не найдено: RSMB дефолты, Twixtor-гайд (только «до 160× медленнее»).
