Это справочник, а не план: что из него берём, решает Олег в каталоге стилей (страница с превью и отметками). Грамматики наших стилей — `docs/styles/*.md`, техники для переноса в код — каталог техник (64, только 2D и WebGL).

Нагрузка — по способу рендера в демо: 2D (Canvas/SVG), WebGL (шейдеры), 3D (three.js с тенями, ray marching, Blender). «У нас» — состояние в reels-motion на дату проверки. Описания — пересказ STYLE.md / промпта стиля, не перевод.
