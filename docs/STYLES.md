# Стили motion-дизайна для reels-motion: что заходит в 2025–2026, как внедрять, что умеет модель

Дата: 2026-10-18. Автор: архитектор. Запрос Олега: «посмотреть стили, которые сейчас хорошо заходят, проанализировать, как их внедрять, и в рамках возможностей самой модели посоветовать, как улучшить и добавить эффекты для моушн-графики».
Источники раздела 1 — вторичные (тренд-отчёты, разборы, галереи; страницы из песочницы частью недоступны, тогда по сниппетам); пометки «подтверждено/вывод» — в таблицах. Числа — гипотезы для калибровки, как и везде в проекте.

## 0. Принцип: стиль = грамматика с числами, а не прилагательное
Опыт lemo-opuscar (51 стиль, «настроен под Opus 5.5») и наш собственный (ROOK против черновика 1) говорят одно: модель воспроизводит стиль, когда он записан как **фиксированная грамматика** — палитра, шрифты, сетка, разрешённые движения с числами, фактура, фирменное движение, запреты, звук. Слова «современно, стильно, дорого» дают «текст на тёмном градиенте».

Формат одного стиля в проекте (`src/styles/<id>.ts` + `docs/styles/<id>.md`, задача 015):
```
id, label, intent (для каких роликов), mode (editorial | cinematic | punch)
palette: пресет OKLCH (src/theme/presets.ts) или новый; сколько цветов; роль акцента
type: display/body/mono из public/fonts; размеры в % высоты кадра (заголовок 7–11 %, hero-цифра 22–29 %, подпись 4.5–7 %); регистр; трекинг
layout: сетка (колонки, поля), плотность, асимметрия, safe zones
motion: темп (PACE calm|crisp), 2–3 кривые из E.*, пружины из SPR.*, стаггер, разрешённые входы/выходы, фирменное движение (ровно 3 раза)
finish: look-пресет (cinematic-fx §5/§3 M), фактуры (@remotion/effects: paper, halftone, noise…), слои фона (recipes.ts)
fx: разрешённые приёмы cinematic-fx с дозой; запреты
captions: стиль субтитров (quiet | trailer | hormozi)
sound: характер SFX/музыки (beat-sync)
tells: 3–5 признаков, по которым стиль узнаётся; slop: 3 способа его испортить
refs: 2–3 эталона Олега с таймкодом
```
Выбор — глазами: композиция `StyleLab` рендерит одну и ту же сцену 3 с (крючок + цифра + подпись) во всех стилях, как `BackgroundPicker` для фонов.

## 1. Стили, которые заходят в 2025–2026 (каталог)
Сквозной сигнал 2026 (сходится у 5+ отчётов — Canva «Imperfect by Design», Depositphotos «Soft Rebellion», Videobolt, Adobe, Stills): **видимое человеческое решение + фактура + ритм важнее полировки**; гладкие дефолты читаются как AI. Canva (проверено): lo-fi +527 %, DIY/скрапбук +90 %, zine/Substack +85 %, liminal +220 %, «clean layout / serif / simple branding» +54 % (это «Opt-Out Era», не «минимализм» вообще), тактильность +30 %; Envato (проверено, окна 4–12 недель, не год к году): «montage» +67 %, «distorted» +45 %, «neon lights» +200 %. Для кодовой системы это хорошая новость: фактуру, ритм и «намеренную неровность» код даёт детерминированно (seed), а полировку — и так умеет.

### 2.3 Что добавить для моушн-графики именно в коде (по отдаче, после 012)
1. **Текстовые элементы 011-Б на `HtmlInCanvas`**: Words/Chain/TypeOn/Roll/MaskRise/Morph/Iris/Cursor — с эффектами (хроматика на слэме, bloom на неоне) без потери readcheck.
2. **Shape-язык**: `src/shapes` — пиктограммы и геометрия из `@remotion/shapes` + `@remotion/paths` (`evolvePath` прорисовка, `interpolatePaths` морф #012, `warpPath`), стрелки-связки (`through`/`ribbon` уже есть), «рождение из точки/щели» вместо fade+y.
3. **Шейдерные фоны-стили**: 3–4 новых рецепта `recipes.ts` под стили (aurora/grainy gradient, chrome/liquid metal псевдо-рефлекс через градиентные полосы + `wave`, halftone-dossier, blueprint уже есть) — все на `speed={0}`/`frame`.
4. **Коллаж/вырезки как система**: `src/collage` — слои PNG с альфой + `outline`/`dropShadow`/`roughenEdges`/`paper`, параллакс 0.3×/1×/1.6×, «на двойках», стикер-обводка; prep: rembg + sha256 (как карточки MIA).
5. **Изометрия и 2.5D**: проекция iso (матрица 30°), стопки «слоёв» с тенью, `cornerPin` для экранов; шаги строятся из точки (gbro: «структура → объект → связки → действие → результат»).
6. **Процедурный «рука/дудл»**: линия с дрожанием по `noise2D` на двойках (line boil 3–5 px, risograph lemo), штрих маркера (`@remotion/rough-notation` из remotion-skills — подчёркивание/обводка/зачёркивание по прогрессу), «нарисовано только что» через `evolvePath`.
7. **Частицы с seed** (только cinematic/punch по дозе): пыль удара, искры от слэма, конфетти-«успех» (#003) — пул из `rand(seed, i)`, никаких генераторов в рантайме.
8. **Аудиореактивный слой** (punch): `loudness.json` → масштаб/свечение одного элемента; спектр для музыкальных роликов.
9. **Стилевые LUT и фактуры в репо**: 2–3 `.cube` (teal-orange, kodak-like, bleach) и тайлы (dust, scratches, lens dirt) через env.manifest; лицензии в THIRD-PARTY.
10. **StyleLab + 4 стиля-грамматики** (задача 015): `swiss-editorial` (№ 16, beauty-studio как база), `pop-impact` (№ 15 + № 7 riso-растр, ROOK как база), `grainy-aurora` (№ 3, курсы AI-CGI, пресет graphite-lime), `kinetic-punch` (№ 1 + № 2 как акцент, промо под бит) — одна сцена во всех четырёх для выбора. Вторая волна по брифу: `zine-collage` (№ 5 + № 6, нужны вырезки), `film-analog` (№ 4 — уже look-пресеты).
