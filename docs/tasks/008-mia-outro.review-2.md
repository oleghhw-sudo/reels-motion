# Ревью 008, динамика v2 (коммит 2f3856c) — принято как черновик, ждёт «ок» Олега

Просмотрено архитектором: черновик 16:9 покадрово (3 к/с), вертикаль, лист кропов погони.

## Принято
- Погоня → переворот с ramp → impact-кадр → карточка MIA работает; схема удара совпадает с прототипом; смаз-склейки на месте; ROOK — кадр 2; HALE → заряд → дверь → финал.
- Readcheck: 3 SHORT подписей — калиброванное исключение (решение Олега «всё да»).

## Замечания архитектора (применять после «ок»/правок Олега)
1. **Финал снова статичный** (15.7–19.6 с: текст на тёмной двери ≈4 с без движения), «MIA» и строка мелкие для телефона. Предложение: «MIA» крупнее ×1.5, строка ≥ 60 px при 1080p; во время удержания — медленный наезд 6 %, пыль/искры по seed, мерцание света из прорези двери, затухание зерна к концу.
2. **ROOK мягче остальных** (исходник 640×503, ×2.5). Вариант: апскейл вырезки (Real-ESRGAN anime ×4, локально) — отдельный шаг prepare, с записью в env.manifest.
3. **Звук:** loudnorm в динамическом режиме из-за пиков SFX — если на слух «качает», убавить SFX на 3 дБ или поставить лимитер перед нормализацией.
4. **Кроп погони 9:16 (рекомендация):** V7 — B (обе машины), V1 — B (MIA за стеклом), V3 — A (больше города, ощущение полёта).
