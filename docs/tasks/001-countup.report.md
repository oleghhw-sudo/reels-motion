## Отклонения от задачи и почему
- Добавлен обязательный проп `id` — нужен `<Readable id>` (стабильный id для readcheck), иначе два счётчика в кадре конфликтуют.
- `theme` кроме `text`, `accent`, `bar` содержит `track`, `chip`, `chipInk` — у спецификации это отдельные цвета (navy3, mint, navy); без них пришлось бы зашить цвета спец. в компонент.
- `fontSize` по умолчанию 208 = 104 × 1080/539 (ячейка галереи растянута на ширину кадра); вся геометрия (чип, полоса, дрожь) масштабируется `k = fontSize/104`. На 1080×1920 при 208 «2 480» с чипом ≈ 750 px — влезает с учётом правой safe-зоны 140 px. Полноразмерный стилл с 208 не делался (в лаборатории 104).
- Чистая логика вынесена в `countup.ts` (см. выше) — ради теста в node без бандлера.
- Компонент занимает бокс 539k×208k; при длинном суффиксе (« грн») число шире ячейки и выходит за бокс (без обрезки) — центр числа остаётся в точке спец. (`cellW/2 + 42`).
