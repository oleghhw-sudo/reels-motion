# 008 — Аутро MIA в Remotion (знакомство с героями, растёт по сериям)

Статус: open (ждёт: 011-А; кадры героев — в outro.yaml; SFX v1 — из нашей CC0/MIT-библиотеки (outro.yaml → sfx)) · Ориентир: 90 мин · Полный рендер: только финал, на Mac
Согласовано Олегом 2026-10-18. Скиллы: reel-cinematic, beat-sync, living-motion, motion-review.

## Решения Олега (2026-10-17/18)
- Вариант A «знакомство с героями», титры на английском. Подписи: MIA · *The Inventor*, DARK · *The Hunter*, BLOND · *Friend or enemy?*; финал *She built the future. They came to take it.* · *To be continued*.
- Такт 4 (затишье) — пустой выбитый проём (V5-04).
- **Аутро разное для разных серий: расширяется по развитию сюжета** (новые герои/планы, другая финальная строка) — значит аутро = данные по сериям, не один захардкоженный ролик.
- Форматы: 16:9 1920×1080 и 9:16 1080×1920 (оба), fps = исходников (24).
- Музыка: Midnight Pursuit, отрезок A с предразгоном 2 доли: 49.739–60.720 с трека (natural, без fade) — УТВЕРЖДЕНО Олегом на слух 2026-10-18 («однозначно лучше»).
- Запреты: Blond убивает Dark, флешбэк школьного двора и молодой Blond, Mia убивает Blond, опознаваемый Blond в прологе; морфинг генерации.

## Данные
- Внешние пути — `env.manifest.json` → `data_dirs`: `MIA_SHORT_DIR` (папка «MIA short»: видео, `_outro-analysis/shots.json`, `_sfx/`, трек). Ничего из неё в git.
- `videos/mia-outro/outro.yaml` — **невосстановимое (гейт 5)**, уже создан архитектором и является единственным источником кадров, кропов, титров и SFX (схема в нём). Билдер его только читает. (Прежний пример схемы здесь удалён 2026-10-18 — в нём были устаревшие кадры BLOND 122/144 и titleSide DARK.)
  Новая серия = новый ключ `epNN` (больше героев → больше тактов; ролик удлиняется на такт за героя).
- Перед сборкой — проверка данных: ни один `liveFrom..freeze+hold` не пересекает `excluded` из `shots.json` (позитивный контроль: подложить запретный интервал → сборка падает с понятной ошибкой).

## Сборка
- Композиции `MiaOutro` (1920×1080) и `MiaOutroVertical` (1080×1920), props `{episode}`; длительность — из данных (такты × герои + затишье + финал).
- План героя: `<OffthreadVideo>` живые 22 кадра → `<Freeze>` на кадре `freeze` на ударе, держится до следующего плана; кроп/кадрирование из данных (вертикаль — свой кроп на каждый план; 720p-исходники в вертикали — с пометкой о резкости в отчёте).
- Оформление стоп-кадра (living-motion, токены 011): лёгкое обесцвечивание/контраст, зерно с seed, наезд 2–4 % за удержание (`dolly`), `hitPulse` +1.5 % на ударе; имя — Oswald (public/fonts), вход на ударе по `SPR.snap` без перелёта на тексте, подпись — stagger 0.18 с; `<Readable>` на всём тексте.
- Затишье: проём, наезд по `dolly`, дыхание камеры; финал: удар → название крупно (`hitPulse` ≤ +10 %), строка и *To be continued* в хвосте звона.
- Звук: отрезок трека → нормализация −14 LUFS / −1 dBTP; SFX по `transientMs` (свист — реверс за 0.2–0.4 с до удара, удар — на ударе), не громче музыки; лицензии → `license-report.md`.
