## 2. 78 UI-звуков CC0 из Real SFX

Новый источник в `sfx/collect.mjs` (`id: "clipwing-uisfx"`), клон в `sfx/raw/` с **закреплённым коммитом** (как у kenney/soundcn), из клона только читаются файлы — **скрипты Real SFX не запускать и скилл не устанавливать**.
- Лицензия: в репо **нет файла LICENSE**, CC0 для звуков заявлен в README (`## Licences`). Если в папке звуков есть свои credits/лицензии по файлам — брать их; иначе `license: "CC0 (README @<commit>)"`. Цитату из README — в отчёт дословно.

## 3. Поиск Openverse
- `sfx/openverse.mjs` (`npm run sfx:openverse -- "<запрос>" [--type click] [--max 20] [--fetch]`): API `https://api.openverse.org/v1/audio/` с `category=sound_effect`, **`license_type=commercial`** (обязательно, отключить нельзя), `page_size`. Анонимно, без регистрации OAuth (для неё нужна почта Олега — не делать; если лимит мешает — записать в отчёт). Пауза между запросами ≥ 1 с, ответы кешировать в `sfx/raw/openverse/cache/` (в git не класть).
- Вывод без `--fetch`: таблица кандидатов — id, title, длительность, лицензия, источник (freesound/wikimedia/…), автор, ссылка на страницу. С `--fetch` — скачать выбранные в `sfx/raw/openverse/<source>__<id>.<ext>`, рядом `.json` с метаданными; дальше обычный `collect.mjs` (источник `openverse`) с классом лицензии из п. 1.
- **Сверка лицензии:** метаданные агрегатора бывают неточны. Для каждого скачанного звука сравнить лицензию из Openverse с лицензией на странице источника (поле `foreign_landing_url`); если страница недоступна или расходится — `licenseClass: "unknown"` с предупреждением, звук не отбрасывать (правило 010).
- `attribution`-звуки → строка атрибуции в manifest; `license-report.md` ролика (из 010) её выводит.
- Пробный прогон: запросы `click`, `footsteps`, `paper rustle`, `whoosh` по `--max 10`; в библиотеку скачать не больше 12 звуков всего (только `free` и `attribution`), остальное — таблица в отчёте.
