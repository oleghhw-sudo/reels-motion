## 012-А — `src/fx` из работающего ep01 (1 сессия)
1. Вынести из `MiaOutro.tsx`/`fx.tsx` в `src/fx` **на текущей DOM/SVG-реализации** (она уже в финале ep01):
   - пресеты (сырые числа в сценах запрещены, как для `E`/`SPR`): `HIT = {S, M, L}`, `LEAD`, `SLAM`, `WHIP`, `LOOK = {none, film, monoHit}` — числа ROOK (cinematic-fx §2); время — секунды, кадры только через `fps` вызывающего;
   - чистые функции: `hitEnvelope`, `leadIn`, `slam`, `whipSmear`, `remapSpeed`;
   - компоненты (функции кадра): `<HitLayer>`, `<LeadIn>`, `<WhipCut>`, `<Slam>`/`<Stamp>`/`<TagPlate>`, `<Look>`.
2. `MiaOutro` переводится на `src/fx` **без изменения картинки**. Регрессия: стиллы удара h2 и финала (те же кадры, что в отчёте финального рендера 008) до/после; попиксельная разница — не более 1 % пикселей с Δ > 8/255. Позитивный контроль: изменённый пресет даёт красное.
3. Зерно — `<Img>`-тайлы вместо `backgroundImage` (`/docs/flickering`).
4. `FxLab24` (1080×1920, 24 fps): плитки S/M/L, слэм, штамп, плашка, хлёст, ramp на синтетическом видео из `scripts/fixtures` (генерируется ffmpeg, детерминированно), look; лист удара L (кадры −4…+8).
5. Тесты `src/fx/fx.test.ts` в `npm run test:motion` (+ `-- --negative` обязан упасть).

## 012-Б — пакеты Remotion под сравнение (1 сессия, Mac)
1. Зависимости — через `env.manifest.json` → `package.json`, ровно 4.0.534: `@remotion/effects`, `@remotion/transitions`, `@remotion/motion-blur`, `@remotion/layout-utils`. Лицензии — в `src/motion/THIRD-PARTY-LICENSES.md` (Remotion License — та же, что у ядра `remotion`, уже в проекте; motion-blur/layout-utils — MIT). Имена параметров — по `.d.ts`, не по памяти.
2. На Mac: вывод `npx remotion gpu --gl=angle` — в отчёт.
3. **A/B в FxLab** для хроматики, зерна, виньетки, смаза, свечения: DOM-версия (012-А) против `@remotion/effects` по листу и времени рендера плитки. Эффект пакета включается пресетом **только если** не хуже по листу и не медленнее ×1.5; иначе остаётся DOM. Решение по каждому — таблицей в отчёте, показ Олегу.
4. **Эффекты на тексте внутри `<HtmlInCanvas>`** (хроматика на слэме, bloom/свечение display-слова) — отдельная группа сравнения: DOM-аналоги (SVG-фильтр на элементе, text-shadow) есть, но не равноценны, поэтому критерий — **по листу удара глазами Олега + readcheck видит текст**; время рендера записывается, ограничение мягкое ×3 (не ×1.5), превышение — вопрос Олегу.
5. `pushCut` (удар M между сценами) и `<Trail>` (шлейф слэма) — плитками FxLab.
6. Схема данных: `look`, `hit: S|M|L` в `scenes.yaml`/`outro.yaml` — с читателем и громкой валидацией (гейт 3); `in`/`ramp`/`holdAfter` уже есть.
