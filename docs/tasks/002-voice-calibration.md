# 002 — Калибровка украинского голоса Fish Audio

Статус: open · Ориентир: 40 мин работы билдера + время Олега на прослушивание · Полный рендер видео: НЕ нужен
Бюджет: только бесплатная модель `s2.1-pro-free` (баланс API-кошелька 0). Платные эндпоинты (ASR, `s2.1-pro`) НЕ вызывать.

## Цель
Выбрать голос и параметры для украинских Reels на эталоне, до любой массовой озвучки (правило «калибровка до масштаба»).
Проверено Олегом 2026-10-16: `POST /v1/tts/stream/with-timestamp` с `model: s2.1-pro-free` → HTTP 200 при нулевом балансе.

## Секреты
Ключ только через `node --env-file=.env …`. `.env` не читать и не печатать (CLAUDE.md «Секреты»). В логах — максимум «ключ задан».

## Что сделать

1. `voice/fish.mjs` — модуль клиента (без SDK: официальные SDK не поддерживают TTS с таймингами).
   - `tts({ text, voiceId, model, format: 'wav', sampleRate: 48000, normalize: false, prosody? })` → SSE `/v1/tts/stream/with-timestamp`:
     склейка всех `audio_base64` по порядку; alignment по `chunk_seq` — заменять снимок (не дописывать); глобальное время = `start/end + chunk_audio_offset_sec`.
     Возвращает `{ audio: Buffer, words: [{ text, start, end }], durationSec }`.
   - `listVoices({ language: 'uk', pageSize, page })` → `GET /model` (бесплатно). Вернуть id, title, автора, теги, task_count, ссылку `https://fish.audio/m/<id>/`.
   - Ошибки 401/402/429 — понятным текстом; 402 = «нужны кредиты», не ретраить.
   - Модель по умолчанию НЕ задавать: передаётся явно (гейт 2 — без неявных значений). В этой задаче везде `s2.1-pro-free`.
2. `voice/phrases.uk.json` — 5 контрольных фраз (эталон, не менять в ходе задачи):
   1. «Погляд, який говорить більше.» — короткий хук.
   2. «Двадцять чотири години на добу, сім днів на тиждень.» — числа прописью.
   3. «Об’єм, довжина й форма — індивідуально, без шаблону.» — апостроф ’ (U+2019), тире.
   4. «Ґрунтовний підхід: Claude Code, After Effects і Remotion в одному процесі.» — ґ + англицизмы.
   5. «Студія працює щодня з дев’ятої до двадцятої, а запис відкритий на тиждень уперед, тому оберіть зручний час заздалегідь.» — длинное предложение, дыхание и темп.
   Плюс отдельной строкой контроль: та же фраза 2, но цифрами «24 години на добу, 7 днів на тиждень» — проверить, как модель читает цифры (normalize для украинского не работает).
3. `voice/calibrate.mjs`:
   - `--list` → печатает до 12 украинских голосов (`listVoices`), сохраняет `out/voice/candidates.json`. СТОП: Олег слушает на сайте и выбирает 3 (вписывает id в `voice/calibration.json`, поле `voices` — этот файл создаёт ОЛЕГ, скрипт его не перезаписывает, гейт 5).
   - `--run` → для каждого голоса из `voice/calibration.json` × 6 фраз: `tts(...)`, сохраняет `out/voice/<voiceSlug>/<n>.wav` и `<n>.words.json`.
   - Автометрики на каждый файл (без ASR):
     - покрытие: число слов в alignment vs слов в тексте (нормализуя пунктуацию; фиксировать расхождения поимённо);
     - монотонность: start ≤ end, start(i+1) ≥ start(i);
     - конец последнего слова vs длительность WAV (ffprobe), разница в мс;
     - паузы > 400 мс между словами (где и сколько);
     - темп: слов/мин и символов/с (для калибровки readcheck — это ЕГО cps);
     - громкость WAV: integrated LUFS и true peak (ffmpeg ebur128).
   - Сводка `out/voice/report.md`: таблица голос × фраза с метриками + колонки для оценки Олега (пустые).
   - Позитивный контроль метрик: прогон проверок на заведомо испорченном alignment (переставленные слова, обрезанный конец) обязан дать красное.
4. Прослушка: `out/voice/listen.html` — статическая страница (без сервера, открывается файлом): по голосу — 6 плееров с текстом фразы и подсветкой текущего слова по `words.json` (проверка таймингов на слух и глаз).
   Оценочная шкала с опорными уровнями (вписать на страницу и в report.md):
   - Естественность: 1 — «робот / артефакты», 3 — «живой, но заметно синтетический», 5 — «не отличить от диктора».
   - Ударения и произношение: 1 — «≥2 ошибки во фразе», 3 — «1 ошибка», 5 — «без ошибок, ’ и ґ корректны».
   - Темп и интонация под Reels: 1 — «монотонно/медленно», 3 — «нормально», 5 — «энергично и разборчиво».
   - Синхрон подсветки: 1 — «уезжает > 0.3 с», 3 — «местами», 5 — «слово в слово».

## Проверки (в отчёт — команды и фактический вывод)
- `node --env-file=.env voice/calibrate.mjs --list` → число найденных голосов.
- Позитивный контроль метрик — красный на испорченных данных, зелёный на чистых.
- После выбора Олега: `--run` → сводка метрик (цифры), путь к `listen.html`.
- Подтвердить в отчёте: ни одного платного вызова (модель в каждом запросе = `s2.1-pro-free`).
