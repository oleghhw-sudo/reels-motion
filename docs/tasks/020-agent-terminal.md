## Формат чисел (`format.ts`)
- Десятичная запятая, минус U+2212, пробел перед «%», «м», «м²» — неразрывный U+00A0; тысячи через U+202F («1 038»).
- Метры: 2 знака (9,25 · 3,58 · 8,70). Площади: 1 знак (99,3 · 22,9 · 113,4). Отклонения: 1 знак со знаком (+0,3 % · −1,9 % · −42,3 %). Точность зон и медиана: целые проценты (89 % · 65 %). Доли `target_shares`: целые проценты, если меньше 5 % — 1 знак (2,5 %). Пиксели стен: 1 знак (10,5 · 17,4).
- Причины (`reasons[0]`) выводятся строкой из `results.json` как есть; тест сверяет число внутри строки с `err` / `check.err_pct` того же объекта.

## Порядок работы
1. `npm run agent:prepare` → копии, миниатюры, `bg.png`, manifest. sha256 пакета до/после.
2. Вёрстка композиции по таймлайну.
3. `npm run test:agent`: `numbers.test.ts` строит список всех строк с числами, которые компоненты выводят (одна функция-реестр `screenNumbers()` в `data.ts`, компоненты берут строки только из неё), и сверяет каждую с таблицей выше. Плюс тесты геометрии (линии в кадре, `ent` снизу). Позитивный контроль: `npm run test:agent -- --negative` подменяет одно значение (например O02.err) → тест обязан упасть, показать вывод.
4. Stills: `npm run still -- AgentTerminal <кадр>` для кадров **30, 180, 315, 495, 720, 900** (1,0 / 6,0 / 10,5 / 16,5 / 24,0 / 30,0 с) и дополнительно **0** и **959** для петли. Открыть каждый кадр, глазами сверить видимые числа с таблицей, ошибки исправить до рендера. Петля: средняя абсолютная разница кадров 0 и 959 по пикселям — в отчёт (цель < 2/255).
5. Если `scripts/readcheck.mjs` работает с 1920×1080 — прогнать на `AgentTerminal`; если он заточен под вертикаль — в отчёте одной строкой, почему пропущен.
6. **Один** полный рендер на Mac:
   `npx remotion render src/index.ts AgentTerminal out/agent-terminal/agent-terminal-v1.mp4 --codec=h264 --crf=18`
   Длительность — `ffprobe` (ожидается 32,000 с, 960 кадров).
7. Отчёт, коммит, push, **СТОП**.
