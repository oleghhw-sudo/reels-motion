Согласовано: Олег «да» 2026-10-19 (замечание: «слишком много звуков, наслоение в начале»). Архитектор.
Где: **только Mac** (медиа, `SFX_EXTERNAL_DIR`, рендер). Порядок: **после того, как 012-А в main** (012-А снимает стиллы MiaOutro; правка `outro.yaml` до нового читателя сломала бы разбор).

## Почему
Разбор микса ep01 по `outro.yaml` + `prepare-assets.mjs`: 0–6.5 с — 12 SFX поверх музыки (riser с первого кадра, свисты на 0.92/1.83/4.13/4.60 с, на каждой карточке удар + щелчок + слэм + конец riser = 4 слоя). Нарушены правила beat-sync: «≤ 2 слоя на ударе», «звук на каждой склейке — слоп», «≥ 2 тишины перед пиком».

## Что сделать
1. **Сохранить старый микс** до любых правок: текущий файл `MANIFEST.music.mixes.ep01.file` → `out/mia-outro/ab/ep01-sfx-v2.wav` (копия, без перекодирования).
2. **Схема `src/videos/mia-outro/model.ts`** (sfx):
   - `whip.on?: string[]` — ссылки `"src:from"` на пункты timeline с `in: whip`; нет поля — как раньше (на всех).
   - `riser.heroes?: string[]` — ключи `names` (DARK, BLOND, OFFICER) или MIA; нет поля — как раньше (на всех карточках).
   - `card` — необязательный; нет — щелчок затвора не ставится.
   - Проверки с понятной ошибкой: ссылка `whip.on` не совпала ровно с одним пунктом `in: whip` → ошибка; герой из `riser.heroes` не встречается среди карточек серии → ошибка.
3. **Читатель — `videos/mia-outro/prepare-assets.mjs`** (гейт 3, в том же коммите): `cue()` для whip — только для пунктов из `whip.on`; riser — только для героев из `riser.heroes`; щелчок — только если `card` задан. `SCRIPT_VERSION` → 2.1.0. В `mixes[ep]` записать `cues` как сейчас (это и есть лист звука).
4. **`videos/mia-outro/outro.yaml`, раздел `episodes.ep01.sfx`** — заменить строки 55–63 ровно на блок ниже (текст архитектора, согласован Олегом; гейт 5 — билдер переносит дословно, ничего не меняет):
