# 025 — Маска человека и лицо по кадрам: macOS Vision (основа) + RVM (запасной)

Согласовано: Олег 2026-10-28 — основа macOS Vision, запасной — лучший из списка с допустимой лицензией. Архитектор. Где: **только Mac, нативная сессия Claude Code** (Vision и AVFoundation есть только в macOS; Linux-VM и облако не подходят). Ориентир: 150 мин. Больше 240 — стоп и причина в отчёт.
Основание: `docs/EFFECTS_PANTRY.md` §J (эффекты говорящей головы, Гвоздарев) и §J.1 (выбор движка маски); потребитель — `cinematic-fx` §3 O.

## Зачем
Половина эффектов §3 O ставит графику «за человека» (цифра, мем, задние карточки орбиты, выход из рамки, вырезки, контур). Нужны покадровая маска фигуры и положение лица для живого видео 9:16. Сейчас в проекте этого нет.

## Выбор движков (не пересматривать в этой задаче)
- **Основа — Apple Vision** `VNGeneratePersonSegmentationRequest`, `qualityLevel = .accurate`, выход `kCVPixelFormatType_OneComponent8`. Встроено в macOS, без лицензий и скачиваний, нейроядро. Минус: каждый кадр считается отдельно, поэтому нужно своё сглаживание во времени (ниже).
- **Запасной — RobustVideoMatting** (`PeterL1n/RobustVideoMatting`, GPL-3.0): рекуррентная сеть с памятью между кадрами, сделана под людей, подсказки не нужны. MatAnyone 2 качественнее, но веса под S-Lab 1.0 (только некоммерческое) — **не брать**. SAM 2/3 + BiRefNet — не в этой задаче.
- RVM — **внешний инструмент вне репо** (GPL): клон и venv в каталоге из новой переменной `RVM_DIR` в `env.manifest.json → data_dirs` (гейт 2); в репо только вызов через subprocess и строка в THIRD-PARTY «внешний инструмент, не распространяется». Коммит RVM зафиксировать в отчёте. Веса `rvm_mobilenetv3` и `rvm_resnet50`, устройство `mps`, при ошибке — `cpu` с предупреждением.

## Этап 0. Разведка (только чтение)
`sw_vers`, чип, `xcode-select -p` и `swiftc --version` (нужны Command Line Tools; если нет — стоп, сообщить Олегу команду установки), python и torch с `mps` (`torch.backends.mps.is_available()`), ffmpeg с `prores_ks`. Есть ли в `videos/` или у Олега дубль с человеком в кадре (см. калибровку).

## Что сделать
1. `tools/matte/vision-matte.swift` (компилируется `swiftc` в `out/bin/vision-matte`, бинарь не в git): вход mp4/mov → кадры через `AVAssetReader` → Vision-маска → апскейл до размера кадра → сглаживание во времени → выход. Плюс `VNDetectFaceRectanglesRequest` на каждом кадре → лицо.
2. Сглаживание маски во времени (рецепт §J, общий для обоих движков, отдельный модуль `tools/matte/temporal.py` или внутри Swift — выбрать и обосновать): порог smoothstep 0.35–0.65 → новая область только в пределах ≈45 px от маски прошлого кадра (dilate 31×31 на рабочем размере 360×640) → ушедший кусок не тянется → смесь 0.3 прошлого / 0.7 текущего → апскейл 1080×1920 → gaussian 1.4 px. Для RVM шаги «порог» и «рост» по флагу, по умолчанию выключены (у него своя память) — решить на калибровке.
3. Лицо: прямоугольник лица Vision; если лица нет — по силуэту (макушка + ширина головы над плечами); сглаживание 0.7 прошлое / 0.3 новое; поле `source: vision|silhouette|hold`.
4. `tools/matte/rvm-matte.py` — тот же выход для RVM (`downsample_ratio` подобрать на калибровке, стартовать с 0.25 для 1080p).
5. Обёртка `npm run matte -- <video> --id <video-id> [--engine vision|rvm] [--from S --to S]` → в каталог из `MATTE_DIR/<id>/` (новая переменная в `env.manifest.json → data_dirs`, гейт 2; файлы большие, не в git):
   - `person.mov` — вырезка человека с альфой (ProRes 4444, 30 fps, 1080×1920) — слой поверх «заднего» слоя в Remotion (`<OffthreadVideo transparent>`);
   - `matte.mp4` — маска в оттенках серого (H.264, crf ≤ 12, yuv420p) — для контура (O4), осколков (O5) и проверки;
   - `face.json` — `{fps, frames: [{t, cx, cy, w, source}]}`;
   - `matte.json` — `{engine, engineVersion (macOS build / RVM commit + веса), params, source:{file, sha256, from, to}, durationSec, renderSecPerSec}`; sha256 выходов — в манифест.
6. Читатель в Remotion (поле + читатель вместе, гейт 3): `src/matte/index.ts` — `loadFace(json)` → `faceAt(t)` (интерполяция), `matteSrc(id)`, компонент `<BehindPerson video person>` = фон-видео → дети (то, что «за человеком») → `person.mov` сверху. Без `mask-image` и `backgroundImage` (`/docs/flickering`), без `backdrop-filter`. Тест на `faceAt`.
7. Лист кадров для проверки: `npm run matte:sheet -- --id <id>` → `out/<id>/matte/sheet.jpg`: 12 кадров, на каждом — кадр, маска поверх красным 40 %, рамка лица; отдельная полоса — разница масок соседних кадров (мерцание видно глазом).

## Калибровка (правило 3) — до подключения к эффектам
**Эталон с известной правдой (обязательный, без участия Олега):** взять 3 отрезка по 5 с из любого видео с человеком (если в репо нет — Олег даёт дубль; не скачивать чужие ролики), вырезать человека RVM `resnet50`, **вручную проверить лист** и затем композитить эту вырезку на 3 других фона (однотонный, кресло/мебель, яркое окно). Маска вырезки = правда. Прогнать оба движка по композитам.
Метрики на кадр: IoU с правдой; ошибка по краю (полоса ±8 px вокруг контура правды); мерцание = средняя |m_t − m_{t−1}| в полосе края на кадрах, где правда почти не меняется; доля кадров с «дырой» в торсе (компонента фона внутри силуэта > 0.5 % площади); скорость (с обработки на 1 с видео).
**Живой эталон (Олег):** дубль 10–15 с, где он жестикулирует, руки перед телом, за спиной кресло или лампа, по возможности окно. Оба движка → листы рядом; вердикт ставит Олег глазами.
Критерий принятия Vision как основы (гипотеза, уточнить по результату): средний IoU ≥ 0.95, мерцание не больше чем у RVM в 1.5 раза, дыр в торсе 0 %, скорость ≤ 1 с на 1 с видео. Если Vision не проходит, а RVM проходит — **не менять решение самому**: таблица и вопрос Олегу.
**Правило переключения на запасной** (записать в отчёт и в `cinematic-fx` §3 O после «да» Олега): какой метрикой и порогом обёртка решает, что для конкретного дубля нужен RVM (например, мерцание или дыры выше порога на прогоне Vision → предупреждение «перегнать `--engine rvm`»). Автоматически не перегонять.
**Позитивный контроль (гейт 4):** (а) кадр с маской, сдвинутой на 20 px, обязан уронить IoU ниже порога; (б) видео без человека (только фон) — маска пустая, `face.source = hold|none`, без ложной фигуры; (в) повторный прогон того же файла даёт побайтно тот же `matte.mp4` (детерминизм; если Vision недетерминирован — записать размер расхождения).
