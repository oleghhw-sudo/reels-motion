# 006 — Звук ставится по измеренному пику + CC0-звуки Barty-Bart в библиотеку

Статус: open · Ориентир: 35 мин · Полный рендер: НЕ нужен
Идеи: howseen (пик звука попадает в событие), Barty-Bart (CC0-набор с манифестом). Разбор: pantry F.

## Часть 1 — постановка по пику
- `src/sfx/cue.ts`: `cueFrame(eventFrame, sound, fps) → frame старта <Audio>` = eventFrame − round(sound.transientMs/1000·fps). `transientMs` уже есть в `sfx/manifest.json` (collect.mjs).
- Если `transientMs` нет — исключение, не тихий 0.
- Тест: на синтетическом WAV с щелчком на 120 мс (сгенерировать ffmpeg в тесте) измеренный пик ±1 мс, старт = событие − 4 кадра при 30 fps; позитивный контроль.

## Часть 2 — CC0-звуки
- Новый источник в `sfx/collect.mjs` (`SOURCES`): Barty-Bart/motion-graphics @3d83d98, папка `skills/sound-effects/sfx`, лицензии брать из их `manifest.json` / `LICENSES.md` ПОСТРОЧНО.
- Лицензию каждого звука записать построчно (гейт 6, ред. 2026-10-18: не запрет, а предупреждение). Звуки не-CC0 — с флагом предупреждения. Ничего не скачивать их скриптами при запуске (`sound_pass.py` не запускать) — только файлы из закреплённого коммита.
- Дедупликация с Kenney (у них часть — Kenney): как уже сделано для soundcn.
- Сводка в отчёт: сколько взято/отброшено по причинам, распределение по типам (особенно whoosh/pop/keystroke — наши пробелы).
- `node sfx/collect.mjs --verify` зелёный; позитивный контроль verify (порча файла → красный) уже есть — показать, что работает и с новым источником.
