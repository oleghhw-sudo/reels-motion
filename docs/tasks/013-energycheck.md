# 013 — Кривая энергии и лист удара: автоматическая проверка «ролик не статичен»

Статус: open (ждёт «да» Олега) · Ориентир: 45 мин · Полный рендер: НЕ нужен · Параллельно с 012 (общих файлов нет)
Причина: черновик 1 аутро MIA прошёл ревью по стиллам и был отклонён Олегом как статичный (docs/ANALYSIS-expressiveness.md §2.4). Правила: motion-review «Дёшево → дорого» п. 3, cinematic-fx §2/§7, motionmaxxing G2 (Apache-2.0, идея: «ни одного прогона > 3 неподвижных кадров»).

## Что сделать
1. `scripts/energycheck.mjs <draft.mp4> [--beats beats.json | --yaml videos/<id>/scenes.yaml|outro.yaml] [--hits "0.917,2.752,…"] [--hold "13.0-14.2"] [--pace calm|crisp] [--fps N]`:
   - ffmpeg: кадры черновика в 0.25 масштаба (ещё раз, если черновик 0.5), серый; энергия кадра f = средняя |Δ| яркости между f и f−1, нормированная на 255 → `energy[f] ∈ [0,1]` (ffmpeg `tblend=all_mode=difference` + `signalstats` YAVG, либо свой расчёт по PNG — выбрать один, обосновать в отчёте);
   - порог «статично» `--static-th` (по умолчанию 0.004 — гипотеза, калибровать на MotionLabKit и черновиках MIA);
   - нарушения: **STATIC** — непрерывный участок ниже порога ≥ 1.2 с (calm/editorial) / ≥ 0.8 с (crisp/punch), кроме интервалов `--hold`; **MISSED_HIT** — на времени удара из карты (`--hits` или `music.hits` из yaml) нет локального максимума в ±1 кадр с амплитудой ≥ 3× медианы; **FLAT_TAIL** — в последней трети нет ни одного пика ≥ 2× медианы; **FLASH_RATE** — > 3 кадров с энергией ≥ 0.5 за любую секунду (пороговое мигание); **FROZEN_FRAMES** — ≥ 4 подряд кадров с энергией < 1e-4 вне `--hold` (G2);
   - выход: таблица в консоль, `out/qa/energy-<name>.json` {fps, energy[], beats[], hits[], violations[]}, и PNG-график `out/qa/energy-<name>.png` (ширина = кадры, отметки долей/ударов, порог) — рисовать без внешних зависимостей (своя растеризация в PNG или через ffmpeg `drawbox` по данным; обосновать);
   - exit 1 при нарушениях, 2 если файл/данные не прочитаны.
2. **Лист удара** `scripts/hitsheet.mjs <Comp> --props … --hits "…" [--before 4 --after 8]` — один бандл, на каждый удар строка кадров −4…+8 через кадр (как `videos/mia-outro/stills.mjs`, но общий для любой композиции), подпись кадра и времени; `out/qa/hitsheet-<Comp>.png`.
3. `--self-test`: две композиции-фикстуры в `src/qa/`: `EnergyStaticFixture` (стоп-кадр 3 с + один удар на 1.5 с без движения) обязана дать ровно STATIC, FROZEN_FRAMES и MISSED_HIT; `MotionLabKit` (уже есть) с `--hits "0.5,1.5,2.5,3.5"` обязан пройти без MISSED_HIT. Рендер фикстур — 0.25 масштаба, короткие.
4. `package.json`: `energycheck`, `hitsheet`; `CLAUDE.md` «Команды» — две строки; motion-review уже ссылается.

## Проверки (в отчёт)
- `node scripts/energycheck.mjs --self-test` → SELF-TEST OK (ровно ожидаемые нарушения, с числами);
- прогон по черновику аутро `out/mia-outro/draft/MiaOutro-draft-0.5.mp4` (если есть на Mac) с `--hits` из `outro.yaml`: таблица и график в отчёт — ожидаемо STATIC на карточках черновика 1 (это подтверждает диагноз);
- лист удара по `MotionLabKit` на 1.5 с.
