## П. 0 — правки по 3б–3в (сделано)
1. **Текст 3б.** Вторая фраза — «Так ставка може прийти з додаткової угоди, а площа й строк — з договору.» Поля картки появляются по порядку слов: Ставка («ставка») → Площа («площа й строк») → Діє до («строк — з договору») → Останній день заяви, Комунальні, Орендодавець (+0.7 с каждое). Нитки не трогал, они по стенду: Ставка → допугода 01.09.2015, остальные поля → договір.
2. **Площа целиком.** Окно вырезки теперь 721 px, а было 640. В него помещаются три значения, «підтверджено» и «БТІ відрізняється від договору» (x 410…1440 картинки, масштаб тот же 0.7 → мелкий текст ≥ 20 px). Камера по вырезке больше не едет. Карточки полей 3–5 под окном сужаются вместе с его появлением, с 340 до 259 px, — подписи короткие и помещаются. Стилл: кадр 4272.
3. **Строки.** Мягкая маска 110 px не помогла: обрубки слов («улася», «йного органу») оставались видны сквозь растворение. Поэтому сделал второй вариант из задачи — кадр по границе колонки. При проезде камеры левый край кадра встаёт на начало колонки «Дата» (x 1650 картинки). Названия событий кончаются раньше (≈ 1600), так что в кадре только Дата · Залишилось · Кому · «Отримано». Стилл: кадр 4800.
4. **Заголовок 3в** появляется в момент раскрытия «Відхилення від еталона» (`EV.deviations.stand`). На панели «Строки» его больше нет. Стиллы: 4938 — заголовка нет, 5004 — он есть.

Сделано заодно, по решению Олега из 031: шесть коротких подписей 3а держатся до следующей вырезки. Причины у вырезок OCR видны до появления следующей. Строка «сума прописом = цифрами» уходит в чергу не раньше, чем за 0.7 с до появления «Черги».
