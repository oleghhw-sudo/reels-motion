## 2. Каркас эффектов O — `src/fx/talking/`
- `window.ts`: `windowOf(t, {t0, t1}) → {u, d, p, inside}`, `backEnv(u, d, back)` — 0 вне окна и на краях, подъём `E.out` за 0.08 с, 1 внутри, спад `E.smooth` за последние `back` (0.2–0.35 с, по умолчанию 0.28), `travel` — доля активной части без хвоста. Кривые — только `E` из `src/motion`.
- `plan.ts`: zod-схема плана `{ matteId, video: {file}, effects: [{fx, t0, t1, back?, sound[], …}] }`, `parsePlan` с громким отказом: окно вне `FX_WINDOW` (§3 O: bignum 1–5 с, figma 1.4–2.0, lens 0.9–1.4), пересечение окон (по t0), слово figma > 10 букв, курсивных букв нет в слове, мелкое слово или звук за концом окна, цифра не 1–2 знака. `checkFace(plan, face, fps, boxOf)` — против `face.json`: bignum требует лицо на каждом кадре окна; figma/lens — 0 пересечений бокса графики с рамкой лица (`cx ± w/2`, высота 1.25·w); возвращает кадры / без лица / пересечения / минимальный зазор.
- `effects.ts`: чистые функции `bignum(u, d)`, `figma(u, d, e)`, `lens(u, d, e)` + боксы `figmaBox`, `lensBox`, `boxOf`; именованные константы `BIGNUM`, `FIGMA`, `LENS` (числа §3 O; что выбрано самим — помечено «выбор»: ширина буквы 0.64 кегля, подъём дуги линзы 60 px, хроматика 2.5 px).

## Что в §3 O не сходится с реальностью Remotion / материала
- **`@remotion/effects` не установлен** — §3 O7 и §4 на него рассчитывают (`fisheye`/`barrelDistortion`/`chromaticAberration` на `<HtmlInCanvas>`). Линза собрана на SVG `feDisplacementMap` по встроенной карте; выглядит как «жидкое стекло» с радиальным смазом к краю, но это не настоящая рефракция `fisheye`. Пакеты — задача 012-Б (env.manifest + package.json + THIRD-PARTY).
- **Числа положения упираются в лицо**: figma y 1352 и линза y 1290 r 140 на крупной говорящей голове (talk-1/2, низ рамки лица 1240–1275) пересекают лицо → `checkFace` отказывает. §3 O не говорит, что делать при крупном плане; в плане `y`/`from`/`to` — параметры, по умолчанию §3 O. Предложение для §3 O: «при крупном лице (низ рамки ниже 1200) figma y = низ лица + 120, линза по той же строке».
- **Линза «по строке субтитров»**: субтитров в пилоте нет (014 не сделана), дуга идёт по телу — содержимое линзы на talk-3 (пиджак) малоинформативно; на фоне с текстурой/текстом эффект читается лучше. Для показа Олегу это честный кадр по числам §3 O.
- **Цифра контуром кремового цвета** на ярком окне (talk-3) малоконтрастна — 6 px штриха видно, но слабо; §3 O толщину штриха и подложку не задаёт (выбор 6 px). На тёмном фоне комнаты будет ярче.
- **Ширина figma ≤ 820**: §3 O не уточняет, до или после ×1.28; взял после растяжения (иначе растянутое слово выходит за правую safe zone 940).
- **Звук**: подсказки §3 O для figma «тик на растяжении» — время относительное (0.55 окна); в yaml записано как число для этого окна (`at: 0.99`), в 026-Б лучше хранить долю окна.
