# Ревью 007, часть А (коммит 69c9b10) — СТОП принят, решение архитектора

Отчёт сильный: замер честный, СТОП по критерию соблюдён, найдено главное — эталон Fish квантован 80 мс, а цифры ломают wav2vec2.

## Диагноз
- Распознавание (ASR) решает две разные задачи сразу: «что сказано» и «когда сказано». Для «когда» мы знаем текст заранее — угадывать его не нужно.
- Выбросы p95 — от слов, которых нет в распознанном тексте (цифры, англицизмы) → интерполяция.

## Решение (вариант 3 из отчёта + поправка критерия) — ЖДЁТ «да» Олега
1. **Тайминги = принудительное выравнивание по тексту сценария** (CTC forced alignment: torchaudio `MMS_FA` или wav2vec2-uk `Yehor/...` через `torchaudio.functional.forced_align`). Новый движок `ctc-script` в `voice/align.mjs`.
   - Перед выравниванием текст сценария нормализуется для речи: числа → слова (тот же код, что в `matchScript`), латиница → кириллическое произношение по словарю `voice/pronounce.uk.json` (Claude Code → «клод код», After Effects → «афтер ефектс», Remotion → «ремоушн»). Словарь — файл Олега/архитектора, скрипт только читает.
   - Слово сценария получает время всегда (нет интерполяции).
2. **Проверка произношения = ASR отдельно** (WhisperX как есть) → `match`/`heard`. Транслитерация латиницы в сопоставлении — по тому же словарю.
3. **Критерий против эталона Fish с учётом его квантования 80 мс:** медиана ≤ 45 мс, p95 ≤ 120 мс (идеальный выравниватель даёт ~20/38). Плюс независимый контроль: +500 мс тишины → ВСЕ слова (включая «24») сдвинуты на 500 ± 33 мс.
   - Ручная разметка эталона (вариант 1) — только если `ctc-script` попадёт в серую зону 45–60 мс.
4. Если `ctc-script` прошёл — `ALIGN_ENGINE=ctc-script` в env.manifest, затем часть Б без изменений.

- Список несовпадений по Fish (голос 8221c35c) совпал с оценкой Олега на слух — ASR-проверка произношения работает как сигнал.
