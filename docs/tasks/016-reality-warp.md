# 016 — «Искажение реальности»: финальная сцена ep01, заход спецназа (глитч + смещение пространства)

Статус: **отложена** (записана как вариант реализации по задумке Олега 2026-10-18; выполнять по отдельной команде) · Ориентир: 2 сессии (прототип ~45 мин + сборка ~90 мин) · Полный рендер: только финал, на Mac · Зависит: 012-А/Б (`src/fx`, `@remotion/effects`), материал сцены в `MIA_SHORT_DIR`
Скиллы: reel-cinematic, cinematic-fx (§2 анатомия удара, §3 H/J/K, §7), beat-sync, motion-review. Режим: cinematic. Правила проекта главнее (гейты CLAUDE.md).

## Задумка Олега
В финальной сцене первой серии, когда спецназ заходит в комнату, начинаются искажения реальности: глитч и смещение пространства. Эффект несёт смысл (реальность ломается), поэтому растёт по нарастающей, привязан к сетке долей и заканчивается коллапсом/срезом, а не «включается фильтром».

## 1. Драматургия: четыре стадии по долям
| Стадия | Когда | Что видит зритель | Сила k |
|---|---|---|---|
| 0 Предвестник | дверь открывается | один «икающий» кадр: повтор кадра ×2 + хроматика 2 px; ручная камера чуть сильнее | 0.05 |
| 1 Просачивание | первые шаги спецназа, 1–2 такта | пространство плывёт локально вокруг двери/источника света; цвет едва уходит | 0.1→0.3 |
| 2 Разлом | удар на доле, 1–2 такта | полосы кадра сдвигаются ступенями по 0.14 с; кадр на 1–2 кадра складывается зеркалом; послеобразы фигур; заикание времени | 0.3→0.7 |
| 3 Коллапс | последний такт до склейки | дыхание линзы импульсами на долях, разрыв кадра с возвратом, перспектива комнаты складывается, 1 кадр негатива, выключение/срез в чёрное на ударе | 0.7→1 |
Между стадиями — скачки на долях (удары из `music.hits`/`beats.json`), внутри стадии k растёт по `E.in`. Ступенчатость обязательна (шаги 0.14 с, как #023 Glitch), плавный blur вместо ступеней — слоп.

## 2. Слои (всё в `@remotion/effects@4.0.534`, параметры сверены с типами пакета; порядок снизу вверх)
1. **Пространство плывёт** (с стадии 1): `noiseDisplacement({ center: focus, radius: 0.2→0.6, strength: 6→28, seed: кадр на двойках, grainSize: 12, passes: 6 })` + медленная `wave({ direction: 'vertical', amplitude: 2→6, wavelength: 180, phase: f(t) })`.
2. **Разлом полосами** (с стадии 2): 2–4 горизонтальные полосы 40–140 px, сдвиг 20–90 px, смена каждые 0.14 с по `rand(seed, шаг)` — копии слоя в `clip-path: inset()` со сдвигом (или `uvTranslate` на регионе); поверх `chromaticAberration({ amount: 6→18, angle: +15°/шаг })`.
3. **Складка пространства**: `mirror({ direction, position: 0.35–0.65, invert })` 1–2 кадра на удар, затем возврат; `tile` — 1 кадр, редко.
4. **Послеобразы фигур**: `<Trail layers={3} lagInFrames={2} trailOpacity={0.5}>` в стадии 2; `lightTrail({ threshold: 0.6, distance: 80–160, decay: 0.9 })` на бликах (фонари, шлемы).
5. **Заикание времени**: `<Freeze>` 2–3 кадра ×2–3 подряд по восьмым; тик на каждый повтор.
6. **Осыпание** (стадия 3): `pixelDissolve({ progress: 0.1→0.35, columns: 48, rows: 86, seed, feather: 0.1 })` — не доводить до 1.
7. **Коллапс**: `barrelDistortion({ amount: 0→0.3 })` импульсами на долях; `zoomBlur({ amount: 40→160, center: focus })`; `tear({ progress: 0→0.4 с возвратом, angle, rotation: 20, jaggedness: 30 })` один раз; `cornerPin` всего кадра ±3–5 %; `invert` 1 кадр; финал — `tvSignalOff({ amount: 0→1 за 6 кадров })` или жёсткий срез в чёрное на ударе.
8. **Цвет**: `saturation 1→0.5`, `levels({ blackPoint: 0→0.12 })`; в стадии 3 на 1 кадр `duotone` сигнального цвета. Зерно/виньетка — из look `film`, не усиливать.
Не делать: сканлайны/«VCR OSD» (это телевизор, не реальность), свечение на всём, эффект на весь кадр с первого кадра, вспышек > 3/с.

## 3. Настоящее смещение пространства (сильный вариант, нужен prep)
- Вырезки фигур спецназа (rembg, как карточки 008) → комната и фигуры получают разный `noiseDisplacement` и разный параллакс (0.3× / 1×): фигуры твёрдые, стены плывут.
- Маска дверного проёма: `cornerPin` только на стену за проёмом, косяк стоит.
- Без вырезок — полнокадровый вариант (§2), честно слабее; записать в отчёт, какой собран.

## 4. Данные и код
- yaml сцены (новый ролик `videos/mia-ep01-final/` или блок в пайплайне серии; невосстановимое — правит человек):
```yaml
warp:
  seed: 7
  anchor: h5                 # удар, с которого стадия 2
  stages: [{on: door, k: 0.05}, {beats: 2, k: 0.3}, {beats: 2, k: 0.7}, {beats: 1, k: 1.0}]
  focus: [0.62, 0.45]        # UV точки двери/схода
  layers: {figures: cutouts/swat_*.png}   # необязательно (§3)
  end: cut-black | tv-off
```
- `src/fx/warp.ts`: `realityWarp(t, cfg, fps) → { effects[], slices[], mirrorFrame, freeze, invert }` — кривая k(t) по стадиям, дискретные события по `rand(seed, шаг)`, квантование на двойках; пресеты `WARP.quiet | mid | hard` (числа — из выбранного прототипа).
- Видео: `<Video>` из `@remotion/media` с `effects` (исходник транскодирован в prepare-assets, иначе fallback на OffthreadVideo теряет effects) или `<OffthreadVideo>` внутри `<HtmlInCanvas>`.
- Звук (beat-sync): низкий дрон + саб со стадии 1; битовый «хруст» на каждом шаге полос; реверс-свист в коллапс; одна доля тишины перед финальным ударом; −14 LUFS / −1 dBTP.

## 5. Порядок работы
1. **Прототип свободной рукой** (reel-director §4 п. 2а): три силы (тихо / средне / жёстко), 3 с, половина разрешения, без ограничений living-motion §12, только `@remotion/effects` + seed. Стиллы границ стадий — в один лист. Олег выбирает.
2. Числа выбранного → `WARP.*`; сцена по yaml; запретные зоны (`shots.json`) проверяются, как в 008.
3. Проверки: лист удара на каждой границе стадий (−4…+8), energycheck (FLASH_RATE ≤ 3/с — позитивный контроль: строб 6/с обязан упасть), детерминизм (два рендера кадра побайтно), черновик 0.5, слух Олега по звуку.
