## 3. Пилот: 3 эффекта (числа — `cinematic-fx` §3 O, не выдумывать свои)
1. **O9 Цифра за головой** (`bignum`, техника «за человеком»): цифра 900 px контуром кремового цвета за человеком (y ≈ 760), вход из размытия и 112 %, всплытие 24 px, уход вверх в размытие. Слой — между видео-фоном и `person.mov`. Без лица в кадре (`faceAt = null`) — эффект не ставится, отказ в схеме.
2. **O8 Выделение как в Figma** (`figma`, техника «текст + UI»): слово по буквам из размытия через 0,022 с, 1–2 буквы курсивной антиквой, рамка выделения курсором с бейджем имени, маркеры, бейдж размера, растяжение ×1.28 на ударном слове, мелкие слова под рамкой; y ≈ 1352, ширина ≤ 820. Слово для пилота: «виділення», курсив — «л», бейдж «Олег», под рамкой «як у Фігмі».
3. **O7 Жидкое стекло** (`lens`, техника «оптика»): линза r 140, дуга (250,1290)→(830,1290), ×1.9 в центре, сильнее к краю, хроматика по краю, блик, ободок, тень; вход из 60 %, растворение. Реализация — копия кадра в круглой маске (`clip-path`/inline-SVG) + `@remotion/effects` (`fisheye`/`barrelDistortion`, `chromaticAberration`) на `<HtmlInCanvas>`; если effects не тянет — SVG `feDisplacementMap` резервом, записать почему.
Звук в этой задаче **не сводить**: для каждого эффекта — таблица подсказок (время от `t0`, тип UI-звука, уровень относительно голоса) из §3 O в `talking-fx.yaml` как данные, без чтения в рендере.

- `npx tsc --noEmit`, тест каркаса (окна, `backEnv` = 0 на краях, отказ схемы на пересечении — позитивный контроль).
- Stills: на каждый эффект — лист из 8 кадров по окну (вход, середина, ударное слово для figma, уход, кадр после окна = исходник побайтно или с разницей ≤ 1/255). Лист: `out/talking-fx/<fx>-sheet.jpg`.
