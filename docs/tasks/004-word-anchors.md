# 004 — Элемент появляется на слово диктора (word anchors + wordcheck)

Статус: blocked (ждёт 002 часть Б и 003) · Ориентир: 45 мин · Полный рендер: НЕ нужен

## Цель
В сценарии писать не секунды, а якоря на слова закадра: `at: { word: "аптека", n: 1 }`. Кадр берётся из `words.json` (Fish, задача 002). Ни у одного разобранного репозитория этого нет — это наш механизм.

## Что сделать
1. `src/voice/anchors.ts` (чистые функции, без React):
   - `normalizeWord(s)` — нижний регистр, убрать пунктуацию, унифицировать апострофы (’ ʼ ' → один), `ґ` не трогать;
   - `resolveAnchor(words, { word, n = 1, edge = 'start' | 'end', offsetSec = 0 }, fps) → frame` — n-е вхождение слова; `edge` — начало или конец слова;
   - если слово не найдено или вхождений меньше n — ИСКЛЮЧЕНИЕ с перечнем ближайших совпадений (не тихий 0).
   - Поддержать якорь по индексу: `{ index: 12 }`.
2. Формат `words.json` — ровно тот, что пишет `voice/fish.mjs` из 002 (`[{ text, start, end }]` в секундах). Не вводить второй формат.
3. `scripts/wordcheck.mjs <words.json> <anchors.json>`:
   - каждое событие попадает в [start, end] своего слова (с `offsetSec` — в допуск ±1 кадр);
   - между соседними сменами ≥ 0.4 с (гипотеза из pantry F, параметр `--min-gap`);
   - отчёт таблицей + `out/qa/wordcheck-*.json`, exit 1 при нарушениях;
   - `--self-test` на фикстуре `src/qa/fixtures/words.fixture.json` с заведомо смещённым якорем, отсутствующим словом и слишком частыми сменами → обязан найти ровно эти 3 нарушения.
4. Тесты `src/voice/anchors.test.ts`: n-е вхождение, апострофы (’ vs '), отсутствующее слово → исключение, детерминизм; позитивный контроль.
5. Пример: композиция `WordAnchorLab` (6 с) — на фикстуре слова подсвечивают 3 карточки через `track` из 003; 2 стилла.

## Проверки
Тесты (+negative), `wordcheck --self-test`, `tsc`, стиллы.

## Вне рамок
Интеграция в scenes.yaml конкретного ролика (будет в задаче ролика), субтитры.
