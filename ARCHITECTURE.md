# reels-motion — архитектура

Личная система моушн-дизайна для Reels (9:16, 1080×1920, 30 fps).
Владелец: Олег. Не продаётся. Целевая среда: Mac, Claude Code desktop, локальный рендер.

## Принцип

Ролик = **данные** (сценарий, тайминги, выбор пресетов) + **библиотека** (компоненты, фоны, звуки).
Claude генерирует данные и редкие уникальные сцены, а не весь ролик с нуля.
Всё, что видно в кадре, — функция номера кадра. Никаких собственных таймеров.

## Конвейер

```
scenes.yaml ──► [voice] TTS (Gemini) ──► voice.wav ──► [align] Whisper + сценарий ──► words.json
                                                     │
                                          [align] ──► timeline.json (сцены, слова → кадры)
                                                     │
            theme preset + background recipe ───────►│
            sfx manifest (утверждённое) ────────────►[cues] ──► sound_cues.json
                                                     │
                                          [render] Remotion ──► stills (QA) ──► MP4
                                                     │
                                          [master] ffmpeg loudnorm −14 LUFS / −1 dBTP
```

Этапы 1 итерации: **лаборатории** (фоны, звуки) → отбор эталонов человеком.
Голос/выравнивание/cues — итерация 2, после калибровки Fish на украинском.

## Структура репо

```
reels-motion/
  ARCHITECTURE.md        этот файл
  CLAUDE.md              гейты ревью для Claude Code
  env.manifest.json      манифест среды (что нужно извне)
  scripts/check-env.mjs  проверка манифеста: громкий отказ со списком
  src/
    Root.tsx             регистрация композиций
    theme/presets.ts     стилевые пресеты (OKLCH-палитры, шрифты)
    backgrounds/         слои и рецепты фонов (все — функции кадра)
    labs/BackgroundLab.tsx  лаборатория фонов
  sfx/
    collect.mjs          сборщик звуков из источников
    raw/                 скачанное (gitignore, воспроизводимо)
    library/             WAV 48k нормализованные (gitignore, воспроизводимо)
    manifest.json        производное: метаданные + лицензии + штамп
    approved.json        НЕВОССТАНОВИМОЕ: отбор человека
    lab/index.html       прослушка с отбором
  approved/backgrounds.json  библиотека рецептов: статус stable | experimental
  videos/<id>/
    scenes.yaml          НЕВОССТАНОВИМОЕ: сценарий + блок background (выбор фона под ЭТОТ ролик)
    assets.manifest.json производное: исходные пути ассетов + sha256 (сами ассеты в git не кладутся)
    assets/              медиа ролика (gitignore, воспроизводимо из источника по манифесту)
```

## Реестр невосстановимого

| Что | Где | Защита |
|---|---|---|
| Отбор звуков | `sfx/approved.json` | git, приватный GitHub |
| Статусы рецептов фонов | `approved/backgrounds.json` | git |
| Сценарии роликов | `videos/*/scenes.yaml` | git |
| Голос (voice id Fish) | `.env` (не в git) | менеджер паролей |

Всё остальное (raw, library, рендеры, manifest.json) воспроизводится командой и в git не кладётся.
Restore доказывается так: свежий clone → `npm run sfx:collect` → прослушка показывает те же отобранные id.

## Контракты среды

Описаны в `env.manifest.json`; `npm run check` падает с перечнем недостающего.
Нет дефолт-путей к данным: всё через манифест.

## Производные и штампы

`sfx/manifest.json` несёт `generatedAt`, `collectorVersion` и sha256 каждого файла.
Прослушка при загрузке сверяет `approved.json` с `manifest.json`: id, которых нет в манифесте, показываются красным.

## Правила дизайна

- Фон = слои: база (шейдер/градиент) → паттерн → зерно → виньетка → акцентный свет.
- Палитры задаются в OKLCH, текст на фоне ≥ 4.5:1 по контрасту (проверка в коде).
- Safe zones 9:16: верх 220 px, низ 380 px, правый край 140 px — без ключевого текста.
- Шрифты обязаны содержать ґ є і ї ʼ (проверка глифов в check). Межстрочный у крупного display-текста ≥ 1.25: точки Ї и хвост Ґ иначе касаются строки выше.
- Звук: пул вариантов на тип, без повторов подряд, лимит плотности, дакинг под голос.

## Порядок работ (правило калибровки)

1. Лаборатории → эталон (фоны 3–5, звуки 10–15 типов) — человек.
2. Калибровка Fish на украинском: 3 голоса × 5 фраз.
3. Пилот 15–20 с, сравнение с эталоном.
4. Только потом — скилл «ролик из scenes.yaml».

## Фон подбирается под каждый ролик (решение 2026-10-10)

Общего «эталона из 3–5 фонов» нет. Фон — часть сценария ролика:
`scenes.yaml → background: { recipe | brandSurface, preset, overrides, perScene }`.
- Кандидатов предлагает Claude (3–4 с обоснованием в одну строку), выбирает Олег; композиция `BackgroundPicker` рендерит кандидатов с реальным текстом хука ролика.
- Рецепт, удачно сделанный под ролик, переводится в `approved/backgrounds.json` со статусом `stable`.
- Для брендовых роликов (сайт клиента) фон = поверхности бренда, снятые с его CSS (`brandSurface`), шейдеры не навязываются.
- Нижняя планка для любого фона неизменна: контраст, кириллица, детерминизм (BackgroundLab + check).
