## Основное правило общения с Олегом

- Любой промпт, команда или фрагмент кода для Олега — ТОЛЬКО копируемым блоком (```), одна команда/шаг — отдельный блок.
- Это касается и коротких фраз для чата Claude Code («открой библиотеку motion-prompt», «используй #005 для заголовка»): никогда не вставлять их в обычный текст — только отдельным копируемым блоком.
- Над каждым блоком: куда вставлять (терминал Mac / чат Claude Code / файл с точным путём / браузер), кому адресовано, порядок и ожидаемый результат.
- Голых блоков без адресата не бывает.

## Роли

- Архитектор — Claude в облачном чате (ТЗ, ревью). Билдер — Claude Code на Mac (реализация). Протокол: `docs/tasks/README.md`.
- Билдер выполняет только задачу из `docs/tasks/NNN-*.md`, пишет отчёт `NNN-*.report.md`, коммит `task NNN: …`, push в main.

## Секреты

- Ключи (FISH_API_KEY и др.) — только в `.env` в корне проекта (в .gitignore, права 600). Олег вводит их сам в терминале.
- Билдер НИКОГДА не читает, не печатает и не просит вставить ключ в чат. `.env` закрыт правилами `.claude/settings.json`.
- Скрипты получают ключ при запуске: `node --env-file=.env <скрипт>`; в логах/отчётах ключ не выводить (максимум «задан/не задан»).

## Где запускать билдера (облако или Mac, 2026-10-18)
- Облачная сессия Claude Code видит только git-репозиторий. Ей недоступны: `MIA_SHORT_DIR` (видео, вырезки, музыка), `sfx/raw`, `sfx/library`, `out/`, `.env` с ключами, звук (`afplay`), прослушка на localhost.
- **В облако:** код, тесты, документы, ревью-правки без медиа (011-Б, линты, правки скриптов, отчёты).
- **Только на Mac:** всё, что читает медиа или ключи — `mia:prepare`, рендеры и стиллы роликов, `sfx:collect`/`sfx:lab`, голос (Gemini), калибровки.
- Облачная сессия, которой не хватает медиа, обязана упасть по гейту 2 (`npm run check`), а не подменять данные.

## Голос

## Шрифты

- Только локальные файлы из `public/fonts` с проверкой глифов ґ є і ї ’. Если когда-то Google Fonts — только `subsets: ['cyrillic', 'latin']`.

## Гейты (нарушение = изменение отклоняется)

1. Всё в кадре — функция `useCurrentFrame()`. Запрещены `Date.now`, `requestAnimationFrame`, CSS-анимации, `setTimeout`, `Math.random()` без seed. Paper Shaders только с `speed={0}` и `frame={кадр/fps*1000}`.
2. Нет дефолт-путей к данным. Новый внешний файл/ключ — сначала в `env.manifest.json`.
3. Новый флаг/состояние без читателя в том же изменении — нельзя.
4. Проверка без показанного красного падения (позитивный контроль) — нельзя.
5. `sfx/approved.json`, `approved/*.json`, `videos/*/scenes.yaml` — невосстановимое. Не перезаписывать скриптами; правит только человек или прослушка/лаборатория по его действию.
6. Лицензия звука/музыки всегда записывается в манифест (источник + лицензия, неизвестная — `unknown`). Жёсткого запрета по лицензии нет (решение Олега 2026-10-18: проекты некоммерческие). Если лицензия ограничивает коммерческое использование, требует атрибуции или неизвестна — ПРЕДУПРЕЖДАТЬ: флаг в манифесте, пометка в прослушке и строка в отчёте сборки ролика. Файлы Sonniss в git не кладутся.
7. Изменения функционала — только после согласования с Олегом.

## Команды

- `npm run check` — проверка среды
- `npm run studio` — Remotion Studio (лаборатория фонов: композиция `BackgroundLab`)
- `npm run sfx:collect` — собрать библиотеку звуков
- `npm run sfx:lab` — прослушка на http://localhost:5174
- `npm run still -- <Composition> <frame>` — кадр в PNG для QA
- `node scripts/readcheck.mjs <Composition> [--props JSON] [--step N] [--cps N] [--min-hold S]` — проверка читаемости текстов (`<Readable>`), stills не рендерит; отчёт `out/qa/readcheck-<Comp>.json`, exit 1 при нарушениях
- `node scripts/readcheck.mjs --self-test` — позитивный контроль readcheck на `ReadcheckFixture` (обязан найти ровно SHORT, OUT_OF_FRAME, UNSAFE)
- `npm run test:motion` — тесты `src/motion` (`-- --negative` — позитивный контроль, обязан упасть)
- `npm run matte -- <video> --id <id> [--engine vision|rvm] [--from S --to S] [--no-thr]` — маска человека и лицо по кадрам → `MATTE_DIR/<id>/{person.mov, matte.mp4, face.json, matte.json}` (задача 025; `MATTE_DIR`, `RVM_DIR` — в `.env`)
- `npm run matte:sheet -- --id <id>` — лист кадров маски → `out/<id>/matte/sheet.jpg` (проверка глазами до метрик)
- `npm run matte:calibrate -- --truth <id> --test <id> | --table | --empty <id> | --self-test --truth <id>` — метрики маски против правды (IoU, край, flickerEdge, дыры); `--self-test` обязан упасть
- `npm run test:matte` — тесты `src/matte` (`-- --negative` — позитивный контроль, обязан упасть)

## Читаемость (readcheck)

- Новый ролик — readcheck обязателен до финального рендера. Каждый значимый текст (заголовки, подписи, метки, кнопка, контакты) обёрнут в `<Readable id text>` (`src/qa/Readable.tsx`, визуально прозрачен).
- Пороги cps/minHold — гипотеза (по умолчанию cps=12, minHold=1.0 с, +0.5 с), калибруются на эталоне, а не принимаются как истина.

## Скиллы роликов (.claude/skills, 2026-10-18)

- `reel-director` — вход: тип ролика (кино / презентация / гибрид), бриф, чекпоинты.
- `reel-cinematic` — история из видео (аутро, трейлер, герои); `reel-presentation` — графика, UI, текст, голос.
- `living-motion` — обязательные правила «живой» анимации (пружины, вес, паузы, камера, морф, запреты).
- `beat-sync` — музыка, доли, SFX по пикам; `motion-review` — проверка до финального рендера.
- `cinematic-fx` (2026-10-18) — словарь AE/CapCut: анатомия удара, ramp, смаз, хроматика, вспышки, impact-кадры, слэм, субтитры по словам, финишная обработка `look`; доза по **режиму** ролика (`mode: editorial | cinematic | punch` в брифе, living-motion §−1). Эталон cinematic — прототип ROOK (`docs/tasks/data/008-proto-rook-card.py`, Opus 5.5 свободной рукой); визуальные задачи билдера — на Opus 5.5, на чекпоинте 2 — прототип удара до спецификации (reel-director §4 п. 2а). Разбор и дорожная карта — `docs/ANALYSIS-expressiveness.md`.
- Нормы взяты из cinetic (MIT, @ecfa660) и product-film-skill (MIT, @fe11efc) — числа это гипотезы, калибруются на эталоне. Гейты этого файла главнее скиллов; выбранные номера motion-prompt главнее токенов living-motion; readcheck главнее норм времени на текст.
