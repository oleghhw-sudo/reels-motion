# reel-director — с чего начинается ролик

Билдер работает только по задаче `docs/tasks/NNN-*.md` (CLAUDE.md, «Роли»). Этот скилл — порядок действий внутри такой задачи.

## 1. Определить тип
| Признак материала и цели | Тип | Ведущий скилл |
|---|---|---|
| Видеофайлы с сюжетом/персонажами; трейлер, аутро, интро серии, знакомство с героями, тизер | **кинематографичный** | reel-cinematic |
| Графика, интерфейс, текст, числа, голос диктора; промо курса/продукта, объяснялка, кейс, инфографика | **презентационный** | reel-presentation |
| Видео-фон/вставки + рисованная графика и текст поверх (промо курса с кадрами работ, кейс клиента с видео) | **гибрид** | reel-presentation (структура) + reel-cinematic (работа с видео) |
Всегда добавляются: **living-motion** (любая графика и текст «живые»), **beat-sync** (если есть музыка/SFX), **motion-review** (перед показом и финалом). Именованные движения — **motion-prompt** (номера от Олега переносятся ровно).

## 2. Бриф → `videos/<id>/brief.md`
- Строка спецификации: `1080x1920@30, 30s, 120BPM, pace: calm|crisp, type: cinematic|presentation|hybrid, audio: <трек/нет>, voice: <провайдер/голос/нет>, lang: uk|en`.
- Цель и зритель одной фразой; площадка (Reels/Shorts/YouTube 16:9); длина серии, если это аутро.
- Источник бренда: `brandSurface` (сайт клиента) или пресет; исключения из запретов living-motion §12 (если бренд использует, например, бежевый или антикву) — записать явно.
- Запреты сюжета (спойлеры) и запретные зоны материала — для кино.
- Лицензии музыки/звуков — записать; ограничения — предупреждение Олегу (гейт 6).
- Чего нет в задаче — не делать.

## 3. Вопросы Олегу (только то, что меняет работу; остальное — разумный дефолт с пометкой в брифе)
Тип и площадка; длина; музыка (свой трек / подобрать / без); голос (Gemini-голос/клон/без) и язык; темп calm или crisp; обязательные кадры/тексты/факты; что нельзя показывать.

## 4. Чекпоинты (стоп и показ Олегу)
1. Бриф + бит-лист (таблица такт/время/картинка/текст/звук).
2. 3 стоп-кадра стиля (крючок, ключевая сцена, кульминация/локап) + фон (BackgroundPicker) или лист кандидатов кадров (HEROES.png) для кино.
3. Черновик в половину разрешения.
4. Финальный рендер — один раз, на Mac.

## 5. Порядок данных
`brief.md` → `scenes.yaml` (невосстановимое: человек правит, билдер предлагает рядом) → голос + `words.json` (align) → `beats.json`/`edit.json` (beat-sync) → `timeline` (кадры из данных) → сцены → проверка → рендер → мастеринг −14 LUFS.

## 6. Экономия
Анализ видео — листами 4×4, ≤ 2 кадров/с, измеримое — командами. Стоп-кадры вместо рендеров. Субагенты — для параллельной реализации независимых сцен и для критиков.
