# motion-review — смотреть кадры, чинить, повторять

Источники: review-loop и critics cinetic (MIT, @ecfa660), review.md product-film-skill (MIT, @fe11efc), правила проекта (CLAUDE.md, память: полный рендер один раз в конце, проверка по stills и аудио отдельно).

## Дёшево → дорого
1. **Стоп-кадры** в моментах, которые важны: каждая доля с событием, каждый стоп-кадр, первый кадр, последний кадр. Бандл один раз — много кадров (не `npx remotion still` в цикле). Несколько кадров склеивать в один лист — экономия токенов.
2. **Листы:** контакт-лист черновика (кадр каждые 0.25 с), лист «вокруг склеек/ударов» (8 кадров через 0.1 с в одной строке на событие). Окна не должны пересекаться.
3. **Черновик** 0.5 разрешения, CRF 24 — для ритма и ощущения. Не финал. По черновику — **кривая энергии** (`scripts/energycheck.mjs`, задача 013): средняя разница соседних кадров по времени + отметки долей и ударов из данных ролика → `out/qa/energy-<Comp>.json` и лист-график; нарушения: STATIC (≥ 1.2 с ниже порога вне задуманного HOLD; ≥ 0.8 с в crisp/punch), MISSED_HIT (на удар карты нет пика ±1 кадр), FLAT_TAIL (последняя треть без пиков), FLASH_RATE (> 3 вспышек/с). Позитивный контроль — композиция-стоп-кадр обязана дать STATIC, MotionLabKit — пики на 0.5/1.5/2.5/3.5 с.
   - **Лист удара**: для каждого удара M/L — кадры −4…+8 через кадр в одну строку: подвод (ramp/наезд/обесцвечивание), кадр удара (вспышка), impact-кадры, отдача (тряска затухает, слэм садится). Черновик 1 аутро MIA провалился именно здесь: по стиллам «на ударе и +2» удар выглядел готовым, а в движении был статичным.
4. **Финальный рендер** — один раз, на Mac, после зелёной проверки (ориентир 15–25 мин). Тяжёлые фактуры — заранее в PNG.

## Автоматические проверки (команды + вывод в отчёт)
- `node scripts/readcheck.mjs <Comp>` — 0 нарушений (или каждое объяснено и согласовано).
- Safe zones (220/140/380) — ничего читаемого вне; текст ≥ 32 px в 9:16.
- Громкость мастера −14 LUFS ±1, true peak ≤ −1 dBTP; голос не маскируется музыкой.
- Синхрон: событие ↔ доля/слово ≤ 1 кадр; звук ставится по `transientMs`.
- Детерминизм: два рендера одного кадра совпадают побайтно (позитивный контроль — кадр с `Math.random` обязан различаться).
- Финальный файл: длительность, fps, разрешение, первый кадр не пустой и не «мягкий», цветовой диапазон (декодировать кадр 0, тёмные не поднялись), для луп-видео последний кадр = первый.
- Лицензии (гейт 6): `license-report.md` — звуки/музыка с ограничениями перечислены.

## Чек-лист глазами (каждый раунд)
- **Живость:** нет ли мёртвых пауз > 1.2 с; паузы на чтение дрейфуют/наезжают; на каждой доле событие; одно hero-движение за раз.
- **Вес:** входы тормозят, выходы разгоняются; нет «замер, потом рывок»; нет перелёта на тексте; приземлений с перелётом ≤ 2.
- **Непрерывность:** главный объект не мигает на склейках; нет кроссфейдов двух копий; текст не летит через текст.
- **Текст:** читается при показе, не перекрыт курсором/элементом, не пересобирается на месте, не режется краем, кириллица без фолбэк-шрифта.
- **Интерфейс:** причина → следствие в тот же кадр; кнопки держат ширину; каждый кадр — валидный скриншот.
- **Слоп** по режиму: editorial — living-motion §12 целиком (свечения, частицы, кроссфейды, текст в углах, градиенты, стекло, bounce); cinematic/punch — cinematic-fx §7 и счётчики §1 (одинаковый zoom-punch на каждой доле, свист на каждой склейке, вспышка без удара, glow на всём, хроматика на тексте для чтения, тряска без затухания/поворота, зерно мерцает каждый кадр, ramp ступеньками, impact-кадр > 3 кадров, субтитры прыгают > 115 %, камера после удара замирает).
- **Удар** (cinematic/punch): у каждого удара M/L есть подвод (видим за ≥ 6 кадров до), кадр удара совпадает со звуком (±1 кадр) и отдача (≥ 6 кадров движения после); размеры ударов чередуются (не два L подряд); бюджет по режиму не превышен — или превышение согласовано.
- **Субтитры по словам**: смена страницы на стартовом кадре слова (±1), страница ≥ 300 мс, не дублируют утверждение сцены, высота строки ≥ 4.5 % кадра, не над лицом/действием.
- **Кино (reel-cinematic):** ни одного кадра из запретных зон (спойлеры, морфинг); склейки на долях; стоп-кадр держится полтакта–такт.
- **Правда:** только реальные факты/числа (для клиента — сверено с его материалами).

## Каталог признаков → исправление (коротко)
| Признак | Исправление |
|---|---|
| Вход фейдом + y:30 у всего | физический вход: маска, рождение из щели/точки, морф |
| Всё одной длительности | длительность от расстояния; лестница UI |
| Кроссфейд по умолчанию | magic move / velocity-matched cut / склейка на доле |
| Камера стоит намертво > 1.5 с | наезд 2–3 %/с + дрейф ≈16 px |
| Мягкая первая секунда | кадр 0 уже в движении, проблема к 1 с |
| Стена текста | цепочка фрагментов по 1–3 слова |
| Мёртвая концовка | локап растёт 10–20 %, факт/CTA читается ≥ 1.7 с |
| Звук на каждое движение | один звук на значимое событие |
| Робот-курсор | дуга, hover, нажатие, человеческие паузы 0.12/0.2/0.3 с |
| Удар «из ниоткуда» (вспышка без подвода) | ramp/наезд/riser за 8–10 кадров, звук в кадр удара, тряска с затуханием после (cinematic-fx §2) |
| Кино статично при зелёных стиллах | лист удара и кривая энергии; удар M минимум на каждом ударе трека; живая пауза на стоп-кадрах |
| Одинаковый эффект на каждой доле | размеры S/M/L чередуются, второй повтор на 30 % тише, третий — только фирменное движение |
| Субтитры-карусель (слово за словом, не прочесть) | 1–3 слова на страницу, ≥ 300 мс, cps по readcheck, активное слово подсветкой |

## Критики (субагенты, если нужно глубже; каждому — листы, бит-лист, код)
- **Режиссёр:** крючок, история без звука, самые слабые 3 с, мёртвое/дешёвое, энергетическая дуга (ранний пик, затишье на 55–85 %, главный пик на 75–90 %), концовка.
- **Текст/арт/UI:** фрагменты и разрывы, стоп-слова, токены цвета/шрифта, размеры, safe zones, правдивость.
- **Звук и синхрон:** источник, рассинхрон, маскировка голоса, громкость, финальный удар — самый громкий/«разрешённый».
- **Криминалист:** хлопки, кадры-призраки, ступеньки, стробинг > 40 px/кадр без blur, бэндинг, z-order, ramp без смешивания, вспышки > 3/с, тряска, открывающая края кадра.
- **Монтажёр AE** (cinematic/punch): смотрит лист удара и кривую энергии; каждый удар — подвод/удар/отдача в кадрах; сравнивает с эталоном брифа (или аутро MIA v2) по 7 критериям (ритм, удар, камера, оптика, текст, звук, финал) 1–10 — ниже 8 по любому = P1.
- **Верификатор:** пытается опровергнуть каждое замечание по кадрам и коду; отклоняет неверное и незаметное на скорости.
Ответ критика: `{id, priority P0|P1|P2, frame, problem, fix: {file, change}}`. P0 — ломает историю/факт/читаемость или запрет; P1 — заметно при обычном просмотре; P2 — только на паузе.

## Ворота выпуска
Нет открытых P0; readcheck зелёный; energycheck без STATIC/MISSED_HIT (или каждое объяснено); громкость в норме; запретных кадров нет; Олег посмотрел черновик **и лист удара**. Только потом финальный рендер. Каждую версию хранить (`out/<id>/v1`, `v2`…), ничего не публиковать без Олега.
