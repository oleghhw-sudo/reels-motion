# cinematic-fx — удар, камера, оптика

Источники: прототип карточки ROOK (архитектор, 2026-10-18, `docs/tasks/data/008-proto-rook-card.py` — «всё да» Олега), каталог motion-prompt (`vendor/motion-prompt`, MIT; номера ниже — его элементы со спецификациями), разбор словаря AE/Premiere/CapCut 2026-10-18 (`docs/ANALYSIS-expressiveness.md` §3 — ссылки там), cinetic/product-film (физика — living-motion). Числа — гипотезы; у чего есть эталон (ROOK) — помечено «ROOK». Кадры указаны **при 24 fps** (кино); при 30/60 fps пересчитывать по миллисекундам, не по кадрам (вспышка 1 кадр @24 = 42 мс = 2–3 кадра @60).

## 0. Принципы
1. **Причина в кадре.** Эффект — следствие события: хлёст — потому что камера рванула; свист — потому что что-то пролетело; вспышка — потому что ударило. Эффект без причины = шаблон (motion-review «слоп»).
2. **Удар — единица смысла.** Любой акцент строится как подвод → удар → отдача (§2). Вспышка «из ниоткуда» запрещена даже в punch.
3. **Доза.** Каждый приём имеет счётчик на ролик (§1). Повторённый приём теряет силу: второй раз — тише/короче на ≈30 %, третий — только если это «фирменное движение».
4. **Пост-обработка — один слой.** Зерно, виньетка, грейд, хроматика краёв, letterbox — это `<Look>` поверх всего ролика (как adjustment layer в AE), не на каждом элементе. Элемент получает только свой локальный эффект (хроматика удара, смаз склейки).
5. **Всё — функция кадра** (гейт 1): шум по seed (`rand`, `hash`, `@remotion/noise`), тряска от номера кадра, зерно тайлами «на двойках». Никаких `Math.random`, CSS-анимаций, таймеров.
6. **Текст для чтения не трогаем.** Слэм, перелёт, шлейф, хроматика — только display-словам (имя героя, одно hero-слово, название, цифра-удар). Фразы и подписи входят по living-motion §3/§6, без эффектов.
7. **Числа из motion-prompt — главнее.** Если Олег назвал номер (#038, #043…), переносить его спецификацию ровно (CLAUDE.md), таблицы ниже — для приёмов без номера и для дозировки.

## 1. Режимы и доза (на ролик 15–30 с; «/10 с» — на каждые 10 секунд)

## 2. Анатомия удара (ROOK — эталон; размер L)
Трёхфазный удар, фазы ставятся по сетке beat-sync; `h` — кадр удара (на доле).

**Подвод (h−10…h−1, 8–10 кадров @24 ≈ 0.35–0.42 с)** — зритель должен *почувствовать*, что сейчас ударит:
- картинка: speed ramp в замедление ×0.55 с межкадровым смешиванием двух соседних кадров исходника (#038; ROOK); на графике скорость 1→0.55 плавно (`E.contact`), не ступенькой;
- камера: наезд 1.00→1.16 с ускорением к удару (`E.contact`, ROOK), центр наезда — лицо/объект удара;
- цвет: насыщенность 1→0.4, контраст 1.05→1.30, тёплый сдвиг +4 (ROOK); хроматика 0→10 px растёт по `E.in` (#111);
- засветка: последние 1–2 кадра — смесь с белым 35 % → 70 % (ROOK);
- звук: riser/реверс-свист, **конец = h** (старт за 0.25–0.4 с; beat-sync §6); музыкальный удар уже в треке — SFX усиливает.

**Удар (h, h+1, h+2)**:
- `h`: белая вспышка 90 % весь кадр, 1 кадр (≥ 40 мс: 1 @24, 2 @60) (ROOK). В ударе M — 60 %, в S — вспышки нет;
- `h+1`, `h+2`: два **impact-кадра** (аниме): фон плоского цвета (1-й — сигнальный красный `#E1140A`, 2-й — цвет карточки героя), 40 чёрных линий скорости из центра героя, фигура — жёсткий ч/б-постер (порог по яркости ≈ 95/255) с белым контуром 25 px (ROOK). Альтернатива без фигуры: инверсия кадра 1 кадр + чёрный кадр;
- тряска всего кадра стартует в `h`: амплитуда 30 px (L) / 12 px (M), затухание ×0.72 за кадр, кадр увеличен на 6 % чтобы не было краёв (ROOK; #024: x 15 px·e^(−5t)·sin(2π·5t), y 11 px, roll 0.02 rad);
- хроматика 14 px в `h+1`, затухание ×0.7 за кадр (ROOK);
- звук: transient удара (boom + click/металл) ровно в `h` по `transientMs` (задача 006, `cueFrame`), sub-drop под финальным ударом; щелчок затвора — если удар = стоп-кадр.

**Отдача (h+3…h+14, ≈ 0.5 с)** — энергия уходит, но ничего не замирает:
- раскрытие нового фона кругом из центра фигуры за 4 кадра (`E.out`), под кругом — стоп-кадр в ч/б с контрастом 1.4 (ROOK);
- фигура «выпрыгивает» 1.14→1.0 на пружине с перелётом (w 24, ζ 0.5 ≈ `SPR.pop`), затем медленный рост +0.12 %/кадр и дрейф 0.6 px/кадр (ROOK) — живая пауза;
- имя (display-слово) влетает `h+3`: масштаб 1.9→1.0 на пружине с перелётом (w 34, ζ 0.5), шлейф 2 копии (+18 % масштаба каждая, α 70/130) только первые 2 кадра (#008 «slam»); вторая тряска 12 px на посадке имени (ROOK);
- номер/штамп `h+5`: 2.2→1.0 (w 30, ζ 0.45); подпись `h+4`: раскрытие маской из плашки за 7 кадров `E.out`, текст въезжает на 60 px (#005);
- лучи вращаются 0.004 рад/кадр, вся карточка наезжает +3.5 % за удержание (`E.out`), зерно по seed, виньетка (ROOK);
- выход из карточки: смаз в сторону, противоположную входу, 2–3 кадра + затемнение 22 %/кадр (ROOK).

Размеры: **L** — всё выше; **M** — без impact-кадров и ramp, вспышка 60 %, тряска 12 px, хроматика 6 px, отдача 6–8 кадров; **S** — zoom-punch 1→1.06–1.08 за 1 кадр, возврат 6–10 кадров `E.out`, без вспышки/тряски (CapCut «beat zoom»: 108–112 % на маркере, обратно за несколько кадров). Правило размера: подряд два удара одного размера — хуже, чем L-S-M.

## 3. Каталог приёмов (назначение · числа · реализация · звук · №)
Формат реализации: «CSS» — style от кадра; «SVG» — фильтр/маска; «DOM×N» — копии слоя; «prep» — предрасчёт в `prepare-assets` (ffmpeg) по данным yaml; «pkg» — пакет Remotion (ставится задачей 012, через env.manifest).

### A. Время
- **Speed ramp** (#038): скорость 1→0.25–0.55 за 8–15 кадров перед ударом, `E.contact`/quad in-out; быстрый участок ×2–4 только *перед* замедлением, не после. Реализация: prep — пересчёт кадров исходника по кривой `src(t)` с межкадровым смешиванием (ffmpeg `minterpolate=mi_mode=blend` или два кадра с α), файл в манифест; в композиции — обычный `<OffthreadVideo>`. Live-вариант (пока нет prep): `<Sequence>` на каждый выходной кадр с `<OffthreadVideo startFrom={srcFrame}>` + второй слой с α для смешивания — дорого, только для коротких подводов. Ниже ×0.3 без оптического потока ступенит — не опускаться. Звук: ramp слышен — музыка не замедляется, SFX-свист/райзер под замедление.
- **Стоп-кадр** (#040): `<Freeze>` на точном кадре, держится полтакта–такт; сопровождается щелчком/ударом и сразу — живой паузой (дрейф/наезд 2–4 %). Не скриншот.
- **На двойках / posterize time**: `onTwos(frame, fps, 12)` — стоп-моушн ощущение для графики/коллажа; зерно всегда на двойках (мерцание каждого кадра читается как шум кодека).
- **Межкадровое смешивание** для любого замедления < ×0.7 (иначе ступеньки).

### B. Склейки
- **Хлёст / смаз** (#043): выход 2–3 кадра + вход 2 кадра (ROOK); peak blur посередине. Направленный смаз — не `blur()`, а **анизотропный**: SVG `feGaussianBlur stdDeviation="40 0"` (по X) или DOM×7 копий со сдвигом по оси и α 1/7 (box-blur вдоль движения); пик 10–20 % ширины кадра (Premiere Directional Blur 100–250 при 1080p); сдвиг кадра по направлению 35 % от размаха смаза. Направления чередуются (←→), выход из карточки — противоположно входу. Звук: свист, пик = кадр склейки.
- **Zoom-through** (#020): экспоненциальный зум к точке (буква/логотип/зрачок), `scale = max^p`, p = 0.8·cubic-in + 0.2·cubic-out, ≈ 20 кадров, blur растёт к середине (Gaussian ≈ 60 px @1080p), смена сцены в точке максимума. Звук: свист с «всасыванием» (реверс) → удар.
- **Smash cut** (#046): голая склейка тихое → громкое, никакого эффекта; работает контраст крупности и громкости. ≤ 1 на ролик.
- **Flash cut**: вспышка 1 кадр 60–90 % (удар M/L) закрывает склейку; тёплый белый (`#FFF4E0`) читается «плёнка», чистый — «строб». Не чаще удара M.
- **Luma / blur dissolve**: растворение через яркость (светлое уходит первым) или через blur 10 px→0 за 0.18 с (`swapIn`) — только для содержимого внутри одного объекта (magic move), не для смены планов. Luma-фейд — клише, ≤ 1.
- **Маска / чернила / жидкость** (#017, #019): раскрытие новой сцены формой (круг из точки удара за 4 кадра — ROOK; «чернила» — SVG-маска с `feTurbulence` seed + `feDisplacementMap`, 8–12 кадров). Причина — удар или объект в кадре.
- **Match cut** (#042), **J-cut / L-cut** (#047/#048): звук следующей сцены за 1–2 доли до склейки / звук предыдущей тянется; ≥ 2 J/L-перехода на ролик с голосом.
- **Спин**: поворот 360° за 10 кадров (5 до + 5 после склейки) с затвором 360° — только punch, ≤ 1.

### C. Камера
- **Zoom-punch** (удар S): 1→1.06–1.08 за 1 кадр (hold), возврат 6–10 кадров `E.out`; на басовых — больше, на слабых — меньше; центр — объект внимания. Не на каждой доле.
- **Тряска с затуханием** (#024): `shakeXY(frame, seed, A·decay^k)` или сумма синусов #024 (x 15·e^(−5t)·sin(2π·5t), y 11·e^(−5t)·cos(2π·6.5t), roll 0.02 рад); L 30 px / M 12 px / посадка имени 12 px; мёртвая через 8–12 кадров; слой увеличен на 6 %, чтобы края не открывались. Тряска без удара — только «предчувствие» (0→4 px за такт, ROOK затишье).
- **Ручная камера** (#034): сумма синусов yaw 0.016·sin(3T)+0.008·sin(7T+1)+0.004·sin(13T+2) (≈ ±1.6°), pitch ±1.2°, roll ±1.6° — или `noise2D(seed, t·f)` с f 0.3–1 Гц, амплитуда 5–8 px (AE `wiggle(2–3, 5–8)`), «бег» — wiggle(3, 55). Всегда с лёгким поворотом (0.3–1°), иначе читается как wiggle по позиции.
- **Dolly-in в паузе**: `E.dolly` 2–4 %/с (living-motion §7); **дыхание** 1.00↔1.02 синусом 0.1–0.2 Гц.
- **Параллакс 2.5D** по стоп-кадру/фото: 2–3 слоя (вырезка rembg → фон, фигура, передний план), сдвиги 0.3× / 1× / 1.6×, наезд 1.06 за план; blur фона 2–4 px при наезде (rack focus 0→12–20 px за 10–15 кадров) (#033).
- **Dolly zoom** (#032): фон растёт ×2 при неподвижном герое за 1–3 с — момент осознания/тревоги; ≤ 1, только по брифу.
- **Крен** −4° на наезде с возвратом 0.4 с (living-motion §8); затвор 180° норма, 360° только спин/хлёст.

### D. Текст и display-слова
- **D1 Слэм** (#008 «slam» + ROOK): масштаб 1.9→1.0 (или 3.4→1 за 0.18 с cubic-in — #008) на пружине w 34 ζ 0.5; шлейф 2 копии первые 2 кадра; после посадки — горизонтальная тряска 10 px·e^(−9t)·sin(38t) и сплющивание 20 %·e^(−11t) (#008). Только display-слово; текст из 1–2 слов; Anton/Unbounded/Oswald по пресету.
- **D2 Штамп**: 2.2→1.0 (w 30 ζ 0.45), 1 кадр перелёта, лёгкий поворот −2°→0; для номеров «#2», меток, печатей.
- **D3 Маска-раскрытие** (#005): плашка растёт 0→100 % за 7–10 кадров `E.out`, текст въезжает на 60 px внутри маски; непрозрачность не меняется.
- **D4 Субтитры по словам** (из `words.json` после выравнивания — не массивом в JSX): группы 1–3 слова (украинский — не длиннее 22–25 символов), смена на стартовом кадре слова; активное слово — цвет акцента и pop 1.10–1.15→1.0 за 100–200 мс (один перелёт 115→95→100 — только punch); шрифт 80–110 px @1080×1920, вес ≥ 700, обводка/тень чёрная (punch: «hormozi» — ALL CAPS, Montserrat Black/Anton, активное слово жёлтое/зелёное); позиция 55–65 % высоты (ниже центра, выше нижней safe zone 380 px); ≤ 17 симв/с (readcheck cps 12 — главнее). Editorial: без pop, подсветка цветом/весом. Эмодзи — только punch, ≤ 2–3 на ролик, по брифу.
- **D5 Печать** (#006): 15–25 симв/с для Reels, каретка, без побуквенного «дрожания».
- **D6 Счётчик** (#007 CountUp): 0.6–1.7 с, tabular-nums, от 85–90 % финала; удар S на посадке.
- **D7 Плашка/lower third**: вход маской, держится ≥ 1.7 с (readcheck), выход на 30 % быстрее входа.

### E. Оптика и финиш
- **Хроматическое двоение** (#111): DOM×3 — копии слоя с изоляцией каналов (SVG `feColorMatrix` R/G/B) и `mix-blend-mode: screen` на чёрном; линейный сдвиг ±d px по X (удар: 6–14 px с затуханием ×0.7/кадр) читается «глитч/удар»; радиальный (масштаб 1+2s / 1+s / 1, s→0.02, ≈ 11 px на краях 1080p) — «линза», для look ≤ 2 px. На тексте для чтения — никогда.
- **Зерно** (#118): тайлы 512², seed, смена на двойках, `mix-blend-mode: overlay/soft-light`, непрозрачность 5–9 % (кино) / 3–5 % (punch); тёмные градиенты — фиксированный шум α ≤ 7/255 против бэндинга. Не мерцать каждый кадр.
- **Виньетка** (#112): радиальный градиент к краям, сила 0.3–0.45, мягкость 0.5 (feather), центр — по композиции, не всегда геометрический.
- **Grade**: насыщенность, контраст, тёплый/холодный сдвиг (ROOK: sat 1.05, con 1.08, warm +4 на живых планах; подвод — в ч/б); teal-orange — тени в бирюзу, света в янтарь, кожа остаётся оранжевой; ч/б (#115) и дуотон (#116) — для стоп-кадра под удар. CSS `filter: saturate() contrast() sepia()`/`feColorMatrix`.
- **Halation / bloom**: копия слоя → порог ярких (≈ 80 %) → blur 20–40 px → тёплый тинт → `screen` 20–35 %; AE Glow стартовые: порог 63 %, радиус 17, интенсивность 3.6 — для неона, в look ниже втрое. Glow на всём — слоп.
- **Light leak** (#119): 4 эллипса от края (радиусы 250/170/95/45 px, янтарь → красный, α 35–50 %), `screen`, покачивание ±6 px; вход 1 с, уход 0.8 с; пик на кадре склейки.
- **Lens flare / light sweep** (#109/#022): flare — на дропе/появлении источника света, 8–15 кадров, `screen`; sweep — полоса 116 px под 24° за 1.05 с по логотипу/кнопке, ≤ 1.
- **Letterbox**: в 9:16 — тонкие полосы 120–200 px или окно 4:5, не 2.39 (съест 38 % кадра); только cinematic, по брифу.
- **Глитч** (#023): 5–6 шагов по 0.14 с, каждый — фиксированное смещение: RGB-сдвиг 7–16 px, 2–4 полосы 10–35 px сдвинуты на 18–64 px, 3 цветных бруска; фон не мигает; seed фиксирован.
- **Impact-кадр** (аниме): см. §2; реализация — фигура с `filter: grayscale(1) contrast(4)` (порог) поверх плоского фона, белый контур = расширенная альфа (prep), линии скорости — SVG из центра.

### F. Графика
- **Поп-арт карточка** (ROOK/008): плоский цвет + растр точек (шаг 22 px, радиус 7×(0.25+0.75·(1−x/W))), 18 лучей α 0.11 вращаются 0.004 рад/кадр, фигура с белой (13–14 px) и чёрной (22 px) обводкой по сглаженному силуэту и жёсткой тенью 18/18 — всё prep из PNG с альфой.
- **Шлейф** (#014, `pkg <Trail layers lagInFrames trailOpacity>`): 6–15 копий, масштаб и α убывают, для пролёта объекта/курсора; слэм — 2 копии.
- **Взрыв/burst** (#003): кольцо 44→90 px, 10 линий и 10 точек, 0.6–0.7 с — момент «успеха/отметки»; punch ≤ 1.
- **Сплющивание** (#011, living-motion §4): по скорости, якорь у кромки.
- **Линии скорости**: 18–40 треугольников из центра, чёрные/белые, ≤ 3 кадра (impact) или α 0.1 фоном (карточка).

## 4. Реализация в Remotion 4.0.534 (проверено по npm 2026-10-18; задача 012, `src/fx`)
**Что уже есть в закреплённой версии** (ставится через env.manifest + package.json, версии ровно 4.0.534):
- **`@remotion/effects`** (лицензия Remotion License — не MIT; для личного некоммерческого проекта допустима, записать в THIRD-PARTY) — ≈80 WebGL2-эффектов как чистые функции параметров: `chromaticAberration({amount, angle})`, `glow({radius, intensity, threshold})`, `vignette({amount, radius, feather})`, `noise({amount, seed})` (зерно: `seed` = f(кадр на двойках)), `scanlines`, `zoomBlur({amount, center, samples})` (смаз zoom-punch), `blur({radius, horizontal, vertical})` (направленный смаз хлёста = только horizontal), `lightTrail({direction, distance, decay})` (шлейф/линии скорости), `lightLeak({seed, hueShift, progress})` (#119), `evolve`/`pixelDissolve` (раскрытия), `noiseDisplacement` (чернила/дрожание), `duotone`, `lut({content})` (3D .cube — грейд teal-orange), `halftone` (растр карточки), `tear`, `tvSignalOff`, `starburst`, `invert`, `levels`, `colorCorrection`… Применяются массивом `effects={[...]}` на canvas-компонентах: `<Img>`, `<Video>` из `@remotion/media`, фигуры `@remotion/shapes`, `<Solid>` и **`<HtmlInCanvas>`** — DOM (в т. ч. текст с `<Readable>`, DOM сохраняется → readcheck видит) рисуется в canvas и получает эффекты. Своё — `createEffect({backend:'webgl2'|'2d', apply})` (постер impact-кадра, halation). Рендер требует `--gl=angle` (у нас уже в `remotion.config.ts`), предпросмотр HtmlInCanvas в Studio — Chrome ≥ 149 с флагом `canvas-draw-element`; в headless-рендере с 4.0.534 всё работает без настроек.
- **`@remotion/transitions`** (Remotion License): `pushCut({flashOpacity, flashTailFrames})` — склейка с punch-in 1.04/1.07 и вспышкой (= удар M); shader-презентации `zoomBlur`, `crossZoom`, `filmBurn({seed})`, `blurSlide`, `linearBlur`, `dissolve`, `ripple` (порты gl-transitions, MIT) через `makeHtmlInCanvasPresentation`; `<TransitionSeries.Overlay>` — light leak поверх склейки без сдвига таймлайна.
- **`@remotion/motion-blur`** (MIT): `<HtmlInCanvasMotionBlur samples shutterAngle>` — честный затвор 180°/360° по субкадрам (норма для хлёста/спина/пролётов); `<CameraMotionBlur samples≤8>` — без GPU (plus-lighter, цвета искажает); `<Trail layers lagInFrames trailOpacity>` — эхо/шлейф (#014, слэм).
- **Ядро `remotion`**: `interpolate(..., {posterize: n})` — «на двойках» нативно; `<Freeze>` — стоп-кадр; speed ramp — только `<OffthreadVideo>` по рецепту Remotion «accelerated video»: накопленное время `remap(frame) = Σ speed(i)`, на каждый кадр `<Sequence from={frame}><OffthreadVideo trimBefore={round(remap)} playbackRate={speed(frame)} src={src+'#disable'}/></Sequence>`; с `<Video>` из `@remotion/media` ramp не работает (проверено по докам), реверс не поддерживается. Межкадровое смешивание — второй слой `trimBefore+1` с α = дробная часть (×2 стоимость) либо prep в ffmpeg.
- **MIT-утилиты**: `@remotion/noise` (есть в проекте) `noise2D(seed, x, y)` — ручная камера/дрейф; `@remotion/paths` `evolvePath` (прорисовка линии), `interpolatePaths` (морф); `@remotion/layout-utils` `fitText`/`fillTextBox` (слэм в ширину, пагинация субтитров); `@remotion/captions` `createTikTokStyleCaptions({captions, combineTokensWithinMilliseconds, breakOnSilenceAfterMilliseconds})` — страницы и токены из `words.json`.
- Что **недоступно без апгрейда** (не делать без задачи): `turbulentDisplace`, `fractalNoise`, `lensBlur` (4.0.537), `effectsOutputSize` (4.0.536).

**Правила кода:**
- Каждый приём — чистая функция `(t | frame, params) → числа/стиль/effects[]` + тонкий компонент; параметры — именованные пресеты (`FX.shake.L`, `FX.ca.hit`, `LOOK.film`); сырые числа в сценах запрещены, как и для `E`/`SPR`.
- Слой пост-обработки `<Look preset>` = один `<HtmlInCanvas>` поверх ролика с цепочкой effects: grade (`colorCorrection`/`lut`) → halation (`glow` низкий порог) → `chromaticAberration` краёв → `vignette` → `noise` (seed на двойках) → letterbox. Пресет и переопределения — в `scenes.yaml`/`outro.yaml` блоком `look`.
- Данные ролика говорят *что* (`in: whip`, `ramp: true`, `hit: L`, `look: film`), код знает *как*. Новое поле в yaml — вместе с читателем в коде (гейт 3) и валидацией схемой (громкий отказ).
- Тяжёлое — заранее: обводки/вырезки, постер-кадры — в `prepare-assets` с sha256 в манифесте; ramp — в кадре по рецепту выше (или prep, если дороже 2× по времени рендера).
- DOM-резервы без WebGL (на случай swangle/CI): хроматика — DOM×3 с SVG `feColorMatrix` + `mix-blend-mode: screen` (рецепт MIT-репо storybynumbers/remotion-glitch-effect); направленный смаз — SVG `feGaussianBlur stdDeviation="40 0"`; зерно — тайлы PNG по seed; виньетка — radial-gradient. Один приём — одна реализация по умолчанию (effects), резерв включается флагом среды, не копией кода.
- Лаборатория `FxLab`: плитка на приём с событием на 0.5/1.5/2.5/3.5 с, стиллы середины и конца, лист одного удара (−4…+8 кадров); FxLab — тот же эталон, что MotionLabKit для физики.
- Проверки: детерминизм (два рендера кадра побайтно), `grep` на запрещённое, readcheck (эффекты не трогают текст для чтения; текст внутри HtmlInCanvas читается), энергия (motion-review), позитивный контроль каждой проверки.

## 6. Звук по приёмам (beat-sync — главнее по сетке и громкости)
| Приём | Звук | Когда пик |
|---|---|---|
| Удар L/M | boom (sub 40–80 Гц + тело 200–500 + щелчок > 3 кГц) | `h`, по `transientMs` |
| Подвод | riser 2–4 доли / реверс-свист 0.25–0.4 с | конец = `h` |
| Хлёст | whoosh | кадр склейки (пик, не старт); старт за 6–12 кадров @30 |
| Стоп-кадр | затвор/щелчок | кадр стопа |
| Слэм имени | slam/металл | посадка (`h+3`…) |
| Zoom-punch S | без звука или tick | доля |
| Финал/взрыв | boom + sub-drop + хвост | `h`, музыка обрывается естественно, holdAfter |
| Субтитры punch | tick/pop на подсветке слова ≤ 1/с, тише музыки | старт слова |
Один звук на событие, два слоя максимум (boom + свист). Свист на каждой склейке — слоп.

## 7. Что читается как шаблон (проверяет motion-review)
Одинаковый zoom-punch на каждой доле; свист на каждой склейке; вспышка без удара; glow на всём; хроматика на тексте для чтения; luma-фейд чаще одного; тряска без затухания или без поворота (wiggle); зерно мерцает каждый кадр; ramp без смешивания (ступеньки); impact-кадр длиннее 3 кадров; subtitles прыгают выше 115 %; letterbox 2.39 в 9:16; эффекты, не привязанные к сетке долей; камера, которая после удара замирает.

## 8. Связь с другими скиллами
- Физика (пружины, вес, перекрытие, камера, паузы) — **living-motion**; этот скилл добавляет приёмы и дозу по режиму (living-motion §−1, §12).
- Где стоять ударам и склейкам — **beat-sync**; размер удара — карта ударов брифа (**reel-director**).
- Кино-сборка (планы, запретные зоны, карточки) — **reel-cinematic**; субтитры и текст — **reel-presentation** + readcheck.
- Проверка — **motion-review**: лист удара, кривая энергии, счётчики дозы.
- Номера Олега — **motion-prompt**, их спецификация главнее таблиц этого файла.
