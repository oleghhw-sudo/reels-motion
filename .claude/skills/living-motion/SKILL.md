# living-motion — анимация, которая живёт

Источники норм: cinetic (Leonxlnx, MIT, @ecfa660 — motion-tokens, craft-rules, taste-and-slop, camera, transitions, product-ui), product-film-skill (Rieranthony, MIT, @fe11efc — kit/spring, move, camera), разбор 230 промптов prompt-motion.com (2026-10). Числа ниже — в секундах; в скобках кадры при 30 fps (наш стандарт). Все числа — стартовые гипотезы, калибруются на эталоне (CLAUDE.md).

## 0. Что значит «живая»
1. **Ничего не стоит.** Пауза на чтение — тоже движение: медленный дрейф/наезд. Полная неподвижность допустима только как задуманный акцент ≤ 0.25 с на тишине.
2. **У движения есть вес.** Входы тормозят, выходы разгоняются; длинный путь — дольше; вторичное догоняет ведущее.
3. **Одна вещь не мигает.** Главный объект переходит из состояния в состояние морфом, а не склейкой/кроссфейдом.
4. **Причина → следствие.** Курсор нажал — кнопка ответила в тот же кадр; число изменилось в кадр приземления.
5. **Ритм.** На каждой доле что-то происходит (beat-sync). Одно hero-движение + ≤ 2 поддерживающих одновременно; «двигается всё сразу» — дешёвка.

## 1. Техника (гейт 1)
- Всё — функция `t = frame / fps`. Пружины — **замкнутая формула** (step-response), значение с несколькими сменами цели = сумма шагов по ключам (`track`), отсортированных по времени. Никаких `spring()` с состоянием между кадрами, CSS transition/keyframes, таймеров, `Math.random` без seed.
- Код движения — только из `src/motion` (и kit после задачи на порт). Сырые `Easing.bezier(...)`/числа пружин внутри сцены — нельзя: только именованные токены ниже. Нет нужной функции → не изобретать в папке ролика, а записать в отчёт «нужен примитив X».
- Анимируемые цвета — hex/OKLCH-токены, не `color-mix()`.
- Индивидуальные `translate/scale/rotate`; никакого `will-change` на том, что масштабирует камера (текст мылится).
- Дробные кадры (motion blur субкадрами) — дискретные состояния через `Math.round`.

## 2. Кривые (токены, ≈3 характера на ролик)
| Токен | cubic-bezier | Для чего |
|---|---|---|
| out | .16,1,.3,1 | появления |
| outSoft | .22,1,.36,1 | мягкая посадка слов |
| in | .7,0,.84,0 | уход/имплозия |
| exit | .55,.055,.675,.19 | разгон в склейку |
| inOut | .87,0,.13,1 | хлёст, морф, сдвиг локапа |
| smooth | .65,0,.35,1 | фейды 0.17–0.23 с, «дыхание» |
| ui | .4,0,.2,1 | мелкие изменения UI |
| cam | .48,.1,0,.9 | камера |
| glide | .47,.2,.15,1 | перемещения 150–350 px |
| dolly | .35,0,.65,1 | медленный наезд в паузе |
| linear | — | только дрейф и часы |
Запрещено: фейд-аут на `out` (хлопает), фейд-ин на `in`, полусинус как огибающая удара.

## 3. Пружины
| Пресет | stiffness/damping/mass | Перелёт | Посадка | Для чего |
|---|---|---|---|---|
| calm | 64/16/1 | 0 | ≈0.9 с | **единственная для текста** |
| firm | 140/24/1 | 0 | ≈0.63 с | появления UI |
| soft | 120/26/1 | 0 | ≈0.68 с | панели, крупные блоки |
| heavy | 90/30/1.4 | 0 | ≈0.93 с | полноэкранные поверхности |
| micro | 500/30/0.6 | ≈0.4 % | ≈0.18 с | чипы, бейджи |
| snap | 260/18/0.7 | ≈6 % | ≈0.37 с | защёлкивание, удары |
| glide (magic move) | 150/20/1 | малый | — | перелёт элемента между сценами |
| camera | 120/30/1.2 | 0 | — | камера, «тяжёлая» |
- **Перелёт:** на тексте — никогда. 1–7 % — только у настоящего приземления (упал на поверхность, вошёл в паз), не больше 2 раз за ролик. Больше одной осцилляции — никогда.
- Пружину, которая может врезаться в соседа или уйти в минус, — ограничивать.

## 4. Вес и follow-through
- **Длительность от расстояния:** calm 0.5 с + 1.6 мс/px; crisp 0.35 с + 1.35 мс/px. Самое медленное движение ролика ≥ 3× самого быстрого.
- Лестница: поповер 0.13–0.2 с; тоггл 0.13–0.17; кнопка→панель ≈0.38; модалка ≈0.43; шит/окно 0.6–0.87; камера 0.9–1.8.
- **Выход = обращённый вход, на ≈30 % короче.**
- **Перекрытие:** вторичное стартует на 55–75 % ведущего, оба заканчивают в пределах 2 кадров. Сосед, которого толкают, сдвигается на ≈0.4 пути и стартует раньше.
- **Форма раньше позиции:** размер/радиус завершаются за ≈0.1 с до контакта.
- **Сплющивание при контакте:** scaleX 1.08→1, scaleY 0.9→1 за ≈0.13 с, якорь на кромке.
- **Форма следует скорости:** пилюля таба тянется до 1.6–1.9× на пике; два края индикатора — на разных пружинах (передний обгоняет).
- **Предвосхищение:** откат 2–4 % пути за 0.1–0.17 с перед hero-движением; 1–2 раза за ролик.
- Взаимодействие опережает эффект на 1 кадр; цвет оседает через 0.33–0.67 с после вызвавшего движения. Новое появляется в акценте и остывает до нейтрального за 0.17–0.5 с.

## 5. Акцент-удар: hitPulse
Огибающая всех акцентов: четверть синуса до пика (≈2 кадра при 60 → 1 кадр при 30), затем экспонента (τ ≈ 0.08 с). Амплитуды: точка/тик +18–30 %; удар по знаку в паузе +1.5 %; деталь на месте +2.5–3 %; камера на кульминации +1.2 %; финальное мигание знака ≤ +10 %. Повторы — `max`, разные причины — сумма.

## 6. Стаггер
- Слова calm: 0.18 с между словами, каждое входит 0.6 с на outSoft; crisp: 0.1 с / 0.43 с на out.
- Соседние элементы 0.07 с; строки 0.1–0.17; сетка 0.07 на колонку, 0.1 на ряд; список — по восьмой доле.
- «Человеческие» паузы 0.12 / 0.2 / 0.3 с. Рябь — 1 кадр на 60 px от источника.
- Повторы ускоряются (второй раз на ≈40 % быстрее). Порядок — по важности, не по DOM.

## 7. Ничего статичного (паузы)
- **Пауза на чтение:** дрейф 0.6–2 px/кадр (30 fps) или наезд 2–5 %/с на `dolly`/`linear`. Больше ≈9 %/с — уже читается как движение.
- **Локап/лого:** держится ≤ 1.5 с; если дольше 1.3 с — растёт 10–20 % за ≈2 с. Слэм-слово растёт 3–5 % за паузу.
- **«Дыхание» камеры:** +2.5 % внутри каждой паузы, снимается следующим движением. Параллакс 0.3× / 1× / 1.6× (2 плана, максимум 3).
- **Лимит простоя:** вне чтения ≤ 1.2 с без видимого события (crisp ≤ 0.8 с). Один задуманный почти-неподвижный HOLD 1–1.6 с перед главным всплеском — можно.

## 8. Камера
- Ключи камеры на тяжёлой пружине, зум — в лог-пространстве.
- Наезд 1.5–3× за 0.5–1.2 с, пик скорости около середины, ≤ 5 % масштаба за кадр. Каждой интеракции — крупный план 2–4× на 0.8–2.6 с; общий план нечитаемого UI ≤ 1.7 с.
- Крен как вторичное: −4° на наезде с возвратом ≈0.4 с; |roll| ≤ 11°.
- Хлёст 0.4–0.5 с, ≤ 1 за спокойный ролик.
- Скорость внутри шота — «U»: быстрый вход, медленно пока читают, разгон в выход.

## 9. Скорость и motion blur
- Обычное движение ≤ 50 px/кадр (30 fps). Текст во время чтения ≤ 6 px/кадр. Подписанные чипы/числа в полёте < 40 px/кадр, иначе текст гасят и проявляют по прилёте.
- Всё быстрее ≈24 px/кадр (30 fps) — с motion blur (субкадры) в мастере; без blur > 40 px/кадр стробит. Подключение blur — отдельная задача.

## 10. Непрерывность и переходы
- **Устройство** (одна форма/цвет) проходит через все сцены на полной непрозрачности; его состояние — функция абсолютного времени. Две копии одного объекта не кроссфейдятся никогда.
- **Magic move:** общий элемент летит в новую позицию/размер на glide-пружине, остальное — блюр-свап (контент входит через 0.18 с, blur 10 px → 0 за 0.18 с). Текст не летит через текст — летят картинки/знаки, слова блюр-свапаются.
- **Velocity-matched cut** (рабочая лошадка): выход разгоняется 0.17–0.4 с, склейка на пике, вход тормозит 0.8–1.4 с, одно экранное направление на блок.
- 6–8 типов переходов на ролик, каждый ≤ 2 раз; одно «фирменное» движение — ровно 3 раза (начало, середина, конец).
- Склейки на сетке (beat-sync).

## 11. Интерфейс в кадре
- Реальные компоненты/«двойники» с часами от кадра. Демоданные — согласованы между собой.
- **Курсор:** только пока действует человек; дуга с прогибом 15–25 % пути; перелёт 0.2–0.33 с на out; hover за ≈0.1 с до нажатия; нажатие — scale 0.88 за ≈0.07 с, отскок ≈0.13 с; кнопка отвечает в тот же кадр.
- **Перетаскивание:** пока зажато — значение следует за курсором; отпустил — пружина назад от того места, где остановилось.
- Число: счёт 0.6–1.7 с на ease-out с tabular-nums от 85–90 % финала, потом держать ≥ 0.4 с; разряды прокатываются 0.1–0.13 с, не кроссфейд (#007 CountUp).
- Загрузка держит ширину кнопки. «Спиннер 1.2 с и ничего» — провал.
- Движущийся элемент не накрывает читаемый текст. Любой кадр на паузе — валидный скриншот приложения.

## 12. Запреты по умолчанию (бренд/решение Олега главнее — тогда записать в brief.md)
Свечения/неон/bloom; частицы, конфетти, искры «AI», блики; кроссфейд по умолчанию; bouncy-easing и перелёт на тексте; побуквенные трюки (кроме одного hero-слова); глитч/RGB-split/light leak/film burn/swirl/ripple; стекло (glassmorphism); многоцветные градиенты и градиентный текст; текст и рамки по углам кадра; eyebrow-лейблы над заголовками («NEW», «01 / …»); стоковые иконки и эмодзи; «замер, потом рывок»; мёртвые паузы; всё появляется фейдом+y:30.
Пары «запрет → замена» — см. motion-review (каталог признаков).

## 13. Связь с другими скиллами
- Числа текста и время на чтение — **readcheck главнее** этих норм (украинские фразы длиннее: держать дольше, фрагменты по 1–3 слова).
- Движения, выбранные из motion-prompt по номеру (#007…), переносятся **ровно по их спецификации** — они главнее токенов этого файла (CLAUDE.md).
- Музыка и места событий — beat-sync. Проверка — motion-review.
