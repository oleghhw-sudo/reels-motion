# reel-cinematic — история из отснятого/сгенерированного материала

Опыт: аутро MIA (2026-10-17/18): черновик 1 по editorial-нормам отклонён как статичный, эталон — динамика v2 (прототип ROOK, `docs/tasks/data/008-proto-rook-card.py`). Режим по умолчанию — **cinematic** (living-motion §−1): приёмы, числа и доза — **cinematic-fx**; физика движения — living-motion; музыка — beat-sync; проверка — motion-review.

## Чем отличается от презентационного ролика
- Главное — **кадр и монтаж**, а не нарисованная графика. Графика (титры, плашки) тонкая и подчинена кадру.
- «Живость» здесь даёт: движение внутри плана, монтаж в долю, **анатомия удара** (подвод с ramp и наездом → вспышка + impact-кадр → отдача с тряской и слэмом имени; cinematic-fx §2), смаз-склейки, стоп-кадр на ударе с живой паузой (наезд/дрейф), финишная обработка (зерно, виньетка, грейд, хроматика краёв — `look: film|trailer`), звук в три слоя (riser → удар → хвост). Не частицы «AI» и не свечение на всём: каждый эффект — следствие удара или движения камеры.
- Спойлеры — реальный риск: аутро/трейлер видят до развязки.

## Шаги
1. **Канон и запреты.** Прочитать сценарий/канон (для MIA — скилл `mia-canon-reference`, если доступен, и `MIA_APPROVED_SCENARIO`). Выписать список «нельзя показывать»: развязки, смерти, повороты, флешбэки с открытым местом в монтаже, лица, скрытые по сценарию. Список — в `brief.md` до выбора кадров.
2. **Инвентарь материала (экономно).** Для каждого файла: ffprobe (формат, fps, длительность, звук), склейки (`select='gt(scene,0.3)'` + ручная проверка на листе — порог пропускает мягкие склейки), контакт-листы 4×4 по 320 px, ≤ 2 кадров/с. Глазами — только листы, не кадры. Измеримое (цвет, громкость, речь) — командами.
   - `_analysis/report.md`, `shots.json` (файл, начало, конец, описание, крупность, кандидат, `excluded` + `reason`: morph | spoiler | spoiler-flashback | artifact).
   - Новые файлы — дописывать, не переиндексировать старые.
3. **Запретные зоны.** Морфинг/артефакты генерации, спойлеры — в `shots.json` с точными границами + запас 0.25 с. Неуверенная граница → более ранняя (безопасная).
4. **Кандидаты по ролям.** Под каждую позицию монтажа (герой, машина, финал) — 3 кандидата: один в кадре, лицо видно, камера стабильна ≥ 1.5 с, живой участок ≥ 1 доли до стоп-кадра, свободная зона под титр. Лист `HEROES.png` (строка на роль, кадр стоп-кадра 480 px, подпись Vn + таймкод + номер кадра). Опознание персонажа — с уровнем уверенности.
5. **Музыка и сетка** — beat-sync. Формула знакомства с героями (v2): на каждого — живой план 1–2 доли с `in: whip` и `ramp: true` на последних 8–10 кадрах → удар L на доле (вспышка 1 кадр, 2 impact-кадра, тряска 30 px) → карточка 3–4 доли (раскрытие кругом, фигура-поп, слэм имени `h+3`, подпись маской `h+4`, лучи, наезд +3.5 %, дрейф) → смаз-выход в противоположную сторону. Затишье трека — под паузу/напряжение (пустой план, наезд 4 %, нарастающая вибрация 0→4 px), финальный удар — название как имя карточки (3 белых кадра, тряска 40 px) + `holdAfter` после обрыва музыки. Карта ударов (S/M/L на каждую долю с событием) — в брифе.
6. **Раскладка.** Таблица: кадры ролика | доля | исходник + кадры исходника | приём | титр | звук. Утверждается Олегом ДО сборки (чекпоинт).
7. **Сборка (Remotion).** Каждый план — `<OffthreadVideo>` с `startFrom` по кадрам исходника; стоп-кадр — тот же кадр, удержанный (`<Freeze>`), не скриншот низкого качества.
   - Оформление стоп-кадра: лёгкое обесцвечивание/контраст, зерно (детерминированное, seed, на двойках), медленный наезд 2–4 % за время удержания, имя — шрифт из `public/fonts` (кириллица/латиница проверены), удар-появление на доле. Карточка героя (поп-арт, обводки, растр, лучи) — cinematic-fx §3 F, слои готовятся в `prepare-assets`.
   - Подвод к удару и склейки — по данным (`ramp: true`, `in: whip`), код — `src/fx` (задача 012): speed ramp по рецепту Remotion на `<OffthreadVideo>`, смаз — направленный blur/`HtmlInCanvasMotionBlur`, хроматика и вспышка — `@remotion/effects`; схема yaml знает каждое поле (громкий отказ на неизвестное).
   - Титры: имя крупно + роль 2–4 слова мелко; читаемость — `<Readable>` + readcheck.
   - Разное разрешение исходников (720p рядом с 4K) — единый мастер (1920×1080 или 1080×1920), апскейл заранее; вертикаль 9:16 кадрировать только из 4K или с проверкой резкости.
   - Звук серии/исходников — дорожкой под музыкой, плавный увод на предразгоне.
8. **Проверка** — motion-review: стоп-кадры на каждой доле с событием, лист «вокруг каждого удара» (8 кадров через 0.1 с), полурезолюционный черновик, только потом финал.

## Правила кадра (гипотезы, калибровать на эталоне)
- Один стоп-кадр с именем — 0.9–1.8 с (полтакта–такт). Меньше — имя не читается, больше — провисает.
- Склейка всегда на доле; смена крупности на соседних планах (общий → крупный), не два одинаковых плана подряд.
- Спокойный финал: пустой/симметричный план с местом под название, звон финального удара — под титры.
- Аутро к серии ≤ 30–40 % длины серии.

## Чего не делать
- Не брать кадры из запретных зон, даже «на полсекунды».
- Не делать кроссфейды между планами без причины; не добавлять свечение/частицы/letterbox 2.39 «для киношности» — только приёмы из карты ударов брифа с дозой cinematic-fx §1; эффект без причины в кадре (хлёст без движения, вспышка без удара) — слоп.
- Не собирать кино по editorial-нормам (без перелёта, +5 % hitPulse, 3 % dolly) — это уже отклонено; минимальная норма кино = анатомия удара M на каждом ударе трека.
- Не менять исходники; работать по ссылкам/копиям в папке анализа.
