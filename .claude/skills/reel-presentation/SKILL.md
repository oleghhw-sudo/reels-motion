# reel-presentation — графика, текст и интерфейс, которые живут

Опора: living-motion (обязательно), beat-sync, motion-review, readcheck (CLAUDE.md). Нормы взяты из cinetic (MIT, @ecfa660 — formats, copy-and-type, product-ui) и product-film-skill (MIT, @fe11efc — story, ingredients), адаптированы под 1080×1920, украинский текст и наши safe zones.

## Форма ролика (15–45 с)
1. **Крючок, 0–1 с.** Кадр 0 уже скомпонован и движется; первая видимая смена ≤ 0.1 с. Начать **внутри проблемы**: она ощутима к 1 с и названа к 2 с. Не «Привіт, сьогодні…», не логотип, не пустой экран.
2. **Поворот** — что меняет ситуацию (одно утверждение).
3. **Доказательство** — продукт/метод в действии: интерфейс, число, до/после. Каждое — своя сцена, одна идея.
4. **Обещание** — результат для зрителя.
5. **Локап** — название/контакт/CTA 1.5–2.5 с, растёт 10–20 %, читается ≥ 1.7 с.
Длительность по задаче: тизер 15–20 с, объяснялка 25–45 с. Последняя треть продолжает двигаться.

## Текст (украинский)
- Фрагменты 1–3 слова (украинские слова длинные), ≤ 22–25 символов; резать по грамматике (не отрывать число от единицы, предлог от слова). Мысль длиннее — цепочка фрагментов.
- Режимы: **build** — фрагменты дописываются в строку (≤ 6–8 слов в кадре), строка один раз пересобирается по центру; **replace** — фрагмент уходит целиком и на том же месте появляется следующий (≤ 4–5 слов).
- Вход слова — living-motion §6 (calm/crisp), без перелёта, без побуквенных трюков. Новое слово — в акценте, остывает.
- Время на чтение — **readcheck** (cps 12, minHold 1.0 с — гипотеза). Если readcheck и нормы движения спорят — побеждает readcheck.
- Текст ≤ 65 % хронометража; на каждые 10 с ≥ 1.5 с без текста (картинка говорит).
- Субтитры голоса — вшиты (фид играет без звука), из `words.json` после выравнивания (voice/align.mjs), не массивом в JSX.
- Стоп-слова (укр. аналоги): «зустрічайте», «уявіть», «революційний», «безшовний», «потужний», «розумний», «все-в-одному», «новий рівень», риторические вопросы, восклицания, тройки «План. Дія. Результат.».
- Каждый значимый текст — `<Readable id text>`.

## Кадр 1080×1920
- Safe zones: верх 220, низ 380, право 140 px (наши, строже cinetic справа). Центр массы ≈ y 880, а не 960.
| y, px | Что |
|---|---|
| 0–220 | только фон/фактура |
| 260–560 | утверждение 1–2 строки, 110–140 px, ≤ 3 слов в строке |
| 600–1380 | продукт/графика шириной ≈ 900 px или за края; UI-текст ≥ 32 px; действие около y 900–1100 |
| 1390–1500 | результат/число ≥ 48 px |
| 1540–1920 | ничего читаемого (подпись и кнопки Instagram) |
- Нижние 40 % не пустые (фактура/край продукта). Не «текст слева — карточка справа».
- Шрифты — только `public/fonts` (кириллица ґ є і ї ’ проверена, `FontGate` с образцом кириллицы). Цвета — токены пресета (OKLCH, контраст ≥ 4.5:1, утверждения ≥ 7:1).
- Вертикаль — отдельная композиция, не кроп 16:9.

## Голос
- Провайдер — Gemini TTS (CLAUDE.md «Голос»), тайминги — только выравнивание `voice/align.mjs`. Словарь произношения латиницы — `voice/pronounce.uk.json`. Числа в тексте для озвучки — словами.
- События на слова диктора — через якоря слов (задача 004), а не «на глаз». Музыка под голос — дакинг (beat-sync).

## Интерфейс и данные
- living-motion §11 (курсор, нажатие, перетаскивание, счётчики, загрузки). Реальная причина → действие → результат; результат держится ≥ 0.6 с до ухода камеры.
- Окно продукта 80–95 % ширины, часто за край; каждой интеракции — крупный план 2–4×.
- Числа: #007 CountUp (formatUk, неразрывный пробел), tabular-nums, прокрутка разрядов. До/после — «было» уходит в серое, «стало» отсчитывается, чип дельты в акценте.
- Демоданные — правдивые (для клиента — с его сайта/материалов), согласованы между сценами.

## Приёмы для вертикали (из библиотеки cinetic, проверены на соцформате)
Нагромождение проблемы с ускорением → заморозка ≤ 0.25 с → поворот на сильную долю; разреженное интро и «дроп» на первой склейке; число как первое утверждение; velocity-handoff cut; якорный элемент на месте при смене фона; конвейер строк (уплывает вверх — следующая на её место); «живая пауза» (наезд 2.4–4.2 %/с); вставка-крупняк на том же рендере; вертикальная стопка слов (слово каждые 0.4–0.5 с, ≤ 3 строк); подсветка слов по долям в уже свёрстанной строке; барабан слова рядом с неподвижной фразой; устройство въезжает уже в движении; жёсткая смена в кадр причины; счёт от почти-финала; локап продолжает собираться в паузе.
Каталог именованных движений — motion-prompt (`pick --local`); выбранное Олегом по номеру — переносится ровно.

## Порядок работы
1. `videos/<id>/brief.md` (reel-director): цель, зритель, строка спецификации `1080x1920@30, 30s, 120BPM, pace: calm|crisp, voice: gemini/<голос>, brand: <источник>`, запреты и исключения бренда.
2. Сценарий-фрагменты + бит-лист `такт | время | картинка | текст (фрагмент, режим) | событие | звук` в `scenes.yaml` (невосстановимое — правит человек; билдер предлагает файлом рядом).
3. **Чекпоинт с Олегом:** бит-лист + 3 стоп-кадра (крючок, одна сцена, кульминация) + выбор фона (BackgroundPicker).
4. Голос → выравнивание → сетка (beat-sync) → сборка сцен из примитивов (`src/motion`, `src/elements`).
5. motion-review: readcheck, стоп-кадр на каждую долю с событием, листы, черновик в половину разрешения. Финальный рендер — один раз, на Mac.
